## 两个模板类型 + 三层拼接

  逐镜变量：`{{参考图清单}}/{{当前分镜}}/{{镜头}}/{{前文分镜}}/{{本章分镜概要}}/{{目标生图模型}}`；

  全章输出靠 `parseChapterPanelPrompts` 按 `【分镜N】` 对位（容错 `第N镜`/MD 标题/顺序兜底/漏段报告）。

  图号与共用属性一律由 `composeFinalPrompt` 在**生图时**拼，所以换状态/调顺序/改画风都不必重跑推导。
- 逐镜批量：滑动窗口前 K=2 镜（`DEFAULT_PREV_PANEL_WINDOW`）带已推导描述，随进度动态刷新；
  复制到外部 AI 时拼接全章 + `COPY_FORMAT_NOTE`（只进复制文本，不进模板）。
- **画面描述输出口径 = 页面结构 + 画面 + 规则参数 + 漫画表现元素 + 图上文字层**（2026-09-27 拍板并追加，详见
  `docs/长篇故事分镜与画面描述职责重划方案.md` 第八、九节）。先写一行「页面结构：」照抄输入，再逐格写「景别与镜头 →
  画面内容（人物位置/动作/表情/场景环境/光线氛围，含分格结构、人物占比、景深、视角关系）→ 漫画表现元素 → 文字气泡层」。
  仍**不输出**资产参考图清单、图号、共用属性、全局画风（这些由 `composeFinalPrompt` 在生图时拼）。
  三块新增：
  1. **规则库写进模板正文**（【漫画画面规则】，用户可改）：分格结构 / 人物占比按景别映射（远景<20%｜中景40~60%｜
     近景60~80%｜特写>80%，铁律）/ 浅景深 / 视角一致性（面对面不得两人同时正脸）/ 光线四要素 / 连续性。
  2. **气泡与旁白框由生图模型画**（【文字气泡与旁白框】）：对白椭圆气尾指嘴；心声云朵边+小圆点链指头；
     **画外（说话人不在本格）气尾不得指向画面内任何人物**，须朝声源方向伸出画框，或改无尾方角框并注明声源；

## 画面描述工件的迁移与归属（2026-09-22 定稿）

`panelPromptService.migratePanelArtworks(artworks, oldPanels, newPanels, chapterId)` →
`{ artworks, droppedPromptCount }`（**重跑分镜与重新导入两条路径共用**）。能继承需**同时**满足：

1. **同序号**且正文**逐字相同** —— 描述写的还是这一页的画面；
2. 描述自身**不是 `stale`** —— 过期是历史欠账，不会因为「这一版正文没变」自己还清。

**不要按页数判断**（曾打算这么写）：分页结构重划时同序号正文必然不同，条件 1 已覆盖；
判页数反而救不了「页数相同但内容全变」。也**不要用内容相似度对位**：描述是正文的扩写而非复述，
实测「正确对」基线仅 0.29、「错配对」能到 0.47，阈值无法区分。

不可继承时的处理：**描述直接丢弃**（正文已变/已过期，留着只会被误用误绑）；**成图跟随**
（用户劳动成果，避免重导入后凭空丢图）——有图才新建「只带成图的记录」。
`droppedPromptCount` 由 `runStoryboard` / `importStoryboard` 带回，页面弹 `notifyDroppedPrompts()`
提示「N 页描述需重新推导」。另有保护：`oldPanels` 为空（首次生成）时整个函数直接返回，不碰任何工件。
丢弃描述时**连 `genPrompts` 一起清掉**（候选条也是照旧画面写的）。

### 提示词模板里的「禁止项」不要写成固定尾段（2026-10-05，asset-prompt 实修）

**病症**：每条资产绘画提示词末尾挂同一段通用禁令清单（「不得出现台词/旁白/水印/签名/编号徽章；不得出现某某之外的其他人物；不得被裁切；三视图必须同比例；不得改变 X 配色、X 发型…」）。

**根因是三处合力**：① `【禁止项】（必须逐条以否定句写进每条提示词）`；② `【用语要求】` 里「【禁止项】例外，必须逐条写进提示词」；③ `【自查】` 里「是否逐条写出了【禁止项】」。**只改一处不生效**。

**正确做法**（可复用到任何「XX 提示词」模板）：
1. **必要条件并进版式声明**（引号内的那句「统一 XX 版式：…」），一次说清、短；
2. 【禁止项】改成「**按需**，不许写成固定尾段」，并把**反面典型原文抄进模板**——模型才知道哪种写法被禁；
3. 给出否定句配额（整条 ≤2 句）与**两类禁写区**：版式类（背景色/完整入画/同比例/标号）、事实类（清单已给的配色/发型/材质/形态/尺寸/状态）；
4. **格式段（硬约束）同步加一句**「不要在末尾附通用禁令清单或固定尾句」——正文讲做法、格式段立硬约束，**两处同改**。

**判定标准**：一段禁令如果「正向描述已经说清」或「只是把清单事实再说一遍」，就是噪音，必须删。

### 漫画排版：结构名词表 / 气泡放置 / 情绪背景（2026-10-05 定稿，四份模板同源）

**结构名不是解析白名单，但四份模板必须同一份词表。**
`storyboardService` 用 `PAGE_LABEL_RE` 原样取页头「·」后的文本，`panel.cellLabel` 直通左栏与画面层且不校验
→ **加结构名零代码**；但「分镜选的名字画面层认不出来」会造成口径断层（老病：词表只有 6 个名字、4 格一律「不规则主从格」）。

三条常量（`promptTemplateRegistry.ts`）是唯一事实源，**storyboard 正文＋格式段、panel-prompt ×2 都插同一份**：
`PANEL_STRUCTURE_NAMES`（名字↔格数）／`PANEL_STRUCTURE_SEMANTICS`（名字→排布语义）／`PANEL_LAYOUT_RULES`（通用规则）。

**12 个结构名**：
1 格 `单格满版／满版出血`｜2 格 `上下错位双格／左右双格／上下双格`｜3 格 `一主两辅／三格递进`｜
4 格 `跨栏主格／左右分栏／不规则主从格`｜5~8 格 `条带连打／多格连打`。

**气泡形状承载情绪**：对白＝椭圆｜喊叫/愤怒＝锯齿尖角爆炸形｜低语/虚弱＝虚线抖动细边或双轮廓｜
心声＝云朵边/波浪边或边缘虚化成雾 + 一串小圆点气尾｜画外＝同对白但**气尾不得指向画面内任何人物**、朝声源伸出画面｜
旁白/说明＝方角矩形框无气尾、贴左上或左下。

**六条放置规则**：① 先说话的在上，同格多气泡按从上到下、从左到右（中文方向），同高左边先读；
② 一格 ≤3 个气泡、总面积 ≤该格 1/3；③ 绝不遮挡眼睛与脸部表情/关键道具/拟声词艺术字；
④ 气尾指向嘴部或下颌、不穿其他角色；⑤ **允许气泡压在两格之间的沟槽留白上**（条漫常见），但不盖邻格关键画面、气尾仍指向本格说话者；
⑥ **用气泡把视线引向下一格**（下一格在下方 → 本格最后一句放下部中央或右下）。另有**沉默格**：一格可以完全不放字。

**`【情绪背景】`**：只在情绪焦点格用｜场景第一次出场必须先用写实环境交代空间｜同一页最多 1~2 格｜
**整体替换写实背景、不是叠滤镜**（人物照旧写实）｜闪亮粉+光斑＝心动｜放射线+网点突变＝震惊｜火焰红放射＝愤怒｜
黑漩涡乱线＝崩溃｜花瓣蕾丝＝恋爱｜猫爪饼干＝可爱｜冷灰薄雾＝失落｜亮黄波纹＝烦躁。

**输出形状**：第一行 `版面：`（不再是 `页面结构：`）｜**分栏就按栏分组**，组前一行 `左栏分镜：`/`右栏分镜：`
（两栏以上写 `第一栏分镜：`…）、**格号跨栏连续不重编**｜每格 `X. 第X格：` + `表现元素：` 一行 + `文字元素：` 一段
（逐条 `- 类型（说话人）：文字（位置；气尾指向）`，类型取 对话气泡／内心气泡／旁白框／说明框／音效，后三者不写说话人）
｜本格没有文字时整段写 `文字元素：无`（旧 token `文字气泡：无` 已归零）。

⚠️ `panel.imagePrompt` 无解析器（改格式自由），但它是**绑定扫描文本**之一
（`panelPromptService:131` = `[panel.content, panel.imagePrompt]`）→ 文字元素里出现画面外角色名会触发 `missing-binding` 误报（老问题）。

### 多格页默认「悬浮散格」，不是条带（2026-10-05 二次收敛，**推翻当日早先的 `条带连打`**）

**病症**：模型产出「1~4 格各占约 12%、沿页面右侧纵向排列」——**等占比 + 同一条页边平铺 = 一列瓷砖**，
「格高不平均」也救不回来。用户否决该版式，要求**分散、错位、悬浮**（每格不占满宽也可占满宽、多个交替）。

**规则常量 `PANEL_FLOAT_RULES`（`promptTemplateRegistry.ts`，与结构名词表一起插四份模板）**：
一格不必占满页宽（**55%~85%**、满宽与偏窄**交替**）｜**水平起点逐格不同**（相邻差 ≥10% 页宽，**禁止沿同一条页边等距平铺成一列等宽窄条**）｜
框外留**统一底衬**（纯色/网点/上一格延续）让格子浮在同一层｜**局部叠压**（压角 ≤ 被压格 1/5，**后读的压住先读的**）｜
偏窄格落中轴或两侧交替，**POV／特写／反应格优先做偏窄浮格**（画幅小＝离读者近）。

**结构名词表（14 名）**：1 格 `单格满版／满版出血`｜2 格 `上下错位双格／左右双格／上下双格`｜
3 格 `一主两辅／三格递进`｜4 格 `跨栏主格／错落浮格／左右分栏／不规则主从格`｜
5~8 格 `悬浮散格／浮格连排／多格连打`。
- `悬浮散格`＝分散疏密不均、留白多（时间跳跃／心理流动／悬疑铺陈）
- `浮格连排`＝沿一条**错位轴线**密集连排、宽窄交替（宽-窄-窄-宽）、可局部叠压（动作连打／POV 序列／特写连打）
- `多格连打`＝泛称，语义已改为「分散错落、格高与水平位置都不平均」
- **`条带连打` 已删除**（连同「格高不得平均分配」「其余格沿动作方向依次递进」两句旧措辞一并列为必须归零）

⚠️ **改这类「两处同源」的句子必须逐份核对**：`panel-prompt` 与 `panel-prompt-chapter` 的格式段那句**起头不同**
（`照抄给定信息里…` vs `照抄该镜给定…`），同一段 old_string 只会命中一份，`replace_all` 不是保险。

### 「表现元素」的 token 唯一性 + 它最终去哪了（2026-10-05）

- 正文小节 = **`【表现元素】`**（原名「漫画表现元素」），逐格输出行 = **`表现元素：`**，**两者必须同 token**。
  历史病：节标题叫「漫画表现元素」、输出行叫「表现元素：」、格式段又禁写「漫画表现元素」→ 模型在两说法间摇摆
  （与 `文字气泡：无` ↔ `无文字` 同类）。现 `漫画表现元素` 已在**正文与格式段双向归零**。
- 该行容纳：拟声词艺术字／速度线·集中线／情绪符号／气氛网点／留白／**情绪背景**（`【情绪背景】` 末条已明写
  「情绪背景属于表现元素，逐格写进该格的「表现元素：」行」）。本格没有就写「表现元素：无」。
- **它会逐字进最终生图提示词**：`panel.imagePrompt` 就是画面描述整段，
  `panelPromptService.buildFinalPromptSections` 的 `return { ..., content: imagePrompt.trim(), ... }` 原样带走 ——
  所以「表现元素」不是中间产物，任何环节都不会把它丢掉。

### 不要在画面里画「引导线」（2026-10-05 用户实报，模板自我成因）

**症状**：画面描述的「表现元素：」行产出
「萧媚视线方向用一条极淡的细引导线穿过人群，指向画面右远处的背影，不压人物面部」。
**漫画里没有画在画面上的引导线**——用户直接判定不要。

**病根在模板**：`PANEL_FLOAT_RULES` 里我写过「格间可用一条**细引导线**、视线或气尾串起阅读路径」。
模型把「视线方向」+「引导线」拼成了现实中不存在的元素。

**正确口径**：**阅读引导靠构图与文字元素自然形成**——人物看向的方向、气尾指向、气泡摆放位置、明暗对比。
**明确写死禁止**：引导线／指示线／视线连线／指向箭头／任何画在画面上的路径标记。

**落点三处（缺一处就会复发）**：
1. `PANEL_FLOAT_RULES`（四份模板共用常量）——「中轴与引导」改「中轴与**视线**」+ 禁止画线；
2. `【表现元素】`（panel-prompt ×2）——加「**不画引导线**」硬约束；
3. `【禁止项】`（panel-prompt ×2）——加禁令。

⚠️ 加这类硬约束时**必须同时写明「不要写进『表现元素：』行」**，否则模型会把它当成每格必答内容，
变成新的**固定尾段**（就是之前修过的老毛病）。
⚠️ 区分开：**速度线／集中线是合法表现元素**（表现运动与冲击），**引导线不是**——两者在模板里要写清差别。

### 分镜字段名的解析契约（写模板必读）

- **`knownField` 是 20 词白名单**：`## 分镜 N · 结构名` / `第X格` / `字段名：内容`
  分别对应 `PAGE_HEADER_RE` / `ANY_CELL_TITLE_RE` / `knownField`。**历次模板改动只能是「加规则」，骨架不要动**。
- 🔴 **加新字段名 → 会变成一句台词（不是被吞掉）**：不带 `- ` 前缀的新字段走 `PLAIN_FIELD_RE` →
  落到 `SPEAKER_RE` → **解析成「说话人 = 字段名，台词 = 值」被画进画面**；带 `- ` 则**静默丢弃**。
  **任何 ≤10 字无标点的新中文字段名都不安全**。变通：折进白名单内已有字段。
- ⚠️ **别用 `备注` 存「页尾钩子」**：`promptAssetService.cellScanText = [content, cast, action, expression, note]`
  会扫 `note` → 钩子提到画面外角色名会触发 `missing-binding` **误报、污染待核对区**。钩子归 `panel-prompt`。
- **`## 章节级尾部段` 不会开成垃圾页**（`PAGE_HEADER_RE` 只认 `分镜 N` / `第 N 页`），
  但会**并进最后一格的「画面」**并进入 `{{当前分镜}}`。

### 格数上限是模板约定，不是代码限制

`cells` 不限长 → 改上限**零代码**。现行 **8 格** + 「叙事页 / 连打页」双模式：
叙事页 1~4 格（对话·环境·情绪，每格 ≤20 字）｜连打页 5~8 格（动作分解·POV 序列·特写连打，
全章 ≤20%、每格 ≤12 字、多数格无台词）。
瓶颈**不在格数、在「有文字的格」有多少**。
⚠️ 页级 ≤60 字必须点明「**无文字的纯画面格不占额度**」；
⚠️ 必须同时给「拆页路由」+「连打页不得塞入对话往返」。
