# 专题：输出格式口径（全链路 Markdown v5 / 长篇分镜格式）

> 从 MEMORY.md 拆出（2026-09-19 定稿，v5）。

## 全链路统一 Markdown

- **口径：输出语法统一为 Markdown（`#` 标题 + `- 字段：内容`），解析专用** —— 各解析器保持专用
  （树状/页格/平铺结构差异大，不抽重型统一算法），但输出语法一致。**不要求「统一解析算法」，禁止过度抽象**。
- **分镜 v5**：格 `### 第X格` 标题 + `- 字段名：内容` 列表行；页头 `## 分镜 N · X格` 不变。
  `serializePanelBlock` / `formatCellsForPrompt` 均输出 markdown。
  解析主路径在 `parseStoryboardResponse` 分支 0（MD_CELL_TITLE_RE）+ 分支 2（FIELD_RE **格内/页级双语义**：
  格内 `镜头`=运镜、台词拆说话人、出场资产进格；页级保持旧语义）。v4/v3/v2 符号全部保留兼容；
  旧数据打开即升级为 v5 文本。
- **资产绘画提示词**：逐条 `## 资产名｜状态名` 标题 + 正文（`ASSET_PROMPT_FORMAT`）；
  assetPromptParser 形态②前缀类本就含 `#`，核心未动，只改协议文案。
- **画面描述整章**：分段标记 `## 分镜 N`（输入清单标记、COPY_FORMAT_NOTE、导入 placeholder 同步）；
  `parseChapterPanelPrompts` 主形态即 md 标题。
  **关键修复：`第N格` 不再被当分镜标记**（旧正则 `(?:镜|格)?` 会把每镜自己的 `第1格：` 格小节误当标记截断正文）
  —— 标记只认 `分镜N` / `第N镜`。
- 提示词模板（OUTPUT_FORMAT_SPECS + 推荐模板）与 `docs/长篇故事剧本与分镜格式定稿.md`
  （标题 v5、2.2 规范、4.4 协议）已同步；旧用户模板需自行「填入推荐模板」。

## 长篇故事 · 分镜格式（v5 Markdown）

页头 `## 分镜 N · 双格`；格 `### 第X格`；字段 `- 字段名：内容`。**入库去包装、出库带包装**。
解析器兼容 v5/v4/v3/v2/旧格式；带模板选择的弹窗默认选中第一个模板（记忆模板有效则优先）。

## 提示词模板：用户自建优先

**能被用户改的拼法必须以用户模板存在**；推荐模板只作新建底稿（「填入推荐模板」），
**不做「模板缺失时内置兜底」**（用户明确否定过）。

### 禁止项的正确落点：版式声明 > 独立禁止段（2026-10-05）

给模板加约束时，**优先落到「版式声明」这类一定会被写出的正向句子里**，而不是单开一段「必须逐条写进每条提示词」的禁止段——
后者会被模型当作"模板必须满足"，产出**每条尾句完全相同**的通用禁令清单（用户实报）。

- 正向句子里能说清的，不要用否定句重说（如「人物完整全身展示」已含「不得被裁切」）。
- 清单已给的事实（配色／发型／材质／尺寸／状态）**禁止**再以「不得改变 X」复述。
- 硬约束（不许附固定尾句）写进**格式段**，正文只写做法 —— 两处必须同改。

### 版式措辞：写「分散错落」还不够，必须写**两个禁写项**（2026-10-05）

让模型做「不规则排版」时，只说「大小不一、错落」它会产出一列**等宽窄条**（每格各占约 12%、沿同一条页边平铺）——
「格高不平均」也拦不住。必须显式给**两个禁写项**：

1. **禁止沿同一条页边等距平铺成一列等宽窄条**（并允许一格只占页宽 55%~85%、满宽与偏窄交替）；
2. **禁止写成「各占约 X%、沿同一条页边依次排列」这类句式**（写进格式段当硬约束）——
   把**被禁的句式原文**给模型看，它才知道要避的是什么。

同理，正向要求也要给量化锚点（水平起点差 ≥10% 页宽、压角 ≤ 被压格 1/5），否则模型会挑最省事的等分。

### 「画面元素」类规则的通用判定：只写**漫画里真实存在的**（2026-10-05）

给模板写「画面里可以出现什么元素」时，最容易犯的错是**把「读者的认知过程」当成「画面上的元素」写下来**：

| 想表达的意思 | 错误写法（会被画成实体） | 正确写法 |
|---|---|---|
| 读者会顺着这条线往下看 | 「用一条细**引导线**串起阅读路径」 | 靠构图与文字元素自然形成（视线方向、气尾指向、气泡位置、明暗对比） |
| 读者会先看这里 | 「画一个**焦点标记**」 | 用明暗对比与留白把主体推出来 |

判定标准：**这句话写的东西，画师能不能拿笔把它画出来？**
能画出来的就是「画面元素」（写错了模型真的会画）；画不出来的就只是「阅读效果」，**不要写成元素名**。

### 剧本「开场与收尾」：爆点前置 + 章末钩子（2026-10-07，用户实报要求）

用户原话：「最开始把小说的爆点展示出来吸引人，结尾留足悬念」。**钩子不是一个模板能装下的**，三层各管一段：

| 位置 | 剧本（章级） | 分镜（页级） | 画面描述（格级） |
|---|---|---|---|
| 开场 | **爆点前置／危机切入**（新增）／禁铺垫 | 按剧本顺序画，不动 | 首屏大画面（既有） |
| 中段 | **每 3~5 场一个爆点**（新增） | 每 3~5 页一爆点（既有） | 每页末格留牵引（既有） |
| 章末 | **六类钩子选一／禁收干净**（新增） | **不写钩子** | **章末页强化**（新增） |

🔴 **分镜层刻意不写钩子**：`备注` 会被 `cellScanText` 扫描，钩子里提到角色名会误报「未绑定」；
测试里有断言锁死（`expect(storyboard).not.toContain('页尾钩子')`）。钩子归**画面描述层**，靠构图与焦点实现、不改台词。

**新增字段 `- 钩子：`**（位置在「场景」之后），**只有第 1 场与最后一场写，其余场景整行省略** ——
防「每场挂一句」退化成固定尾段（同 §19 媒介质感锚的病）。剧本不经解析器，加字段零风险。

**前置三禁**（每条对应一类真实事故，缺一条就出事）：

1. **不得新增原文没有的事件** —— 只改呈现顺序，不得改写／拼接／移花接木（否则模型为「更炸」自己编事故）；
2. **只给入口，不给答案** —— 揭晓／结果／身份亮明的那一拍必须留在原场景（一起前置 → 后文揭晓时读者早知道了）；
3. **不得跨越服装／时期的状态切换点** —— 前置片段若处于已换装状态，第 1 格就要声明一个后面的资产状态，
   **下游分镜判断不出来**。这是前置方案唯一真正的坑。

**章末**：`剧情目的` 里那个 `收束` 枚举等于鼓励把章末「收」掉 → 现要求末场的剧情目的**必须含「高潮」或「转折」**；
钩子**只调落点不调内容**（原文本身平静时，把末拍停在「平静之下最不对劲的那一处」，不许自己编事故）；
钩子必须**画得出来**（❌「气氛变得紧张」✅「他推开门，屋里的灯是亮的」）。

**章末页怎么判（零代码）**：`panel-prompt` 拿得到 `{{本章分镜概要}}`（`buildChapterOutline` = `分镜N：内容` 每行一镜）
与 `{{当前分镜}}` 的「分镜序号」→ 比一下即可；整章模式（`panel-prompt-chapter`）直接是清单最后一镜。

口径与改前/改后样例见 `docs/剧本开场与章末钩子-口径.md`；方案文档 §20。

### 分镜「叙事连贯」：全章台词 + 旁白要能连读成一条故事线（2026-10-07，用户实报要求）

用户原话：「所有分镜把整个事件串联起来，主要通过旁白内容和对话内容，这两个要能知道整个小说的走向和故事」。

**缺口不是分辨率，是「过桥」**：旧口径「旁白来源唯一＝逐字继承剧本/原文、没有叙述文字就整行省略」漏了一类情况 ——
**剧本与原文都没有叙述句、而这一页已经跨了时间／地点／视角** → 这一页一个字都没有 → 文字连读断线。
这正是 McCloud 六种镜头衔接里的 **scene-to-scene**：「Always pair with a caption or an establishing shot or **the reader is lost**」
（另一本分镜模板 FAQ 点出最常被漏的两件事：**「这一格是谁的视角」与「距上一格过了多久」**）。

**做法（零字段新增，全部折进既有 `旁白`／`台词` —— 新字段名会被解析成一句台词，见 §11.1）**：
- `storyboard` 新增 **【叙事连贯】节**：**三类断层必须用旁白过桥**（时间跨越／地点转移／视角切换）／
  取材只允许来自**剧本场景头**、**只交代跨度不写剧情**／因果断口用台词或旁白补前因／
  **主线必须落在文字上**（不靠画面暗示，画面是模型生成的、不保证画准剧情）／**不许复述**（旁白复述画面＝漫画脚本最常见错误）／
  **只在断层处补、不是每页都写**／末条「连读自检」明确**不写进任何一格的输出**。
- `【旁白怎么写】`：「来源唯一」拆成**两种职责、两个来源**（原文旁白＝逐字／衔接旁白＝跨度的桥，取材剧本场景头）；
  一格最多一条 + 衔接旁白优先落在本页没有台词类文字的那一格；末条改为「没有叙述文字**且本页没有跨越**才整行省略」。
- `【台词怎么写】`：补「**台词是故事主线的主要载体**」——关键台词一句不漏、额度不够拆格拆页，不许为压字数丢关键台词。
- **格式段**同步硬约束（全章连起来必须能独立看懂 + 三类断层各一条旁白 + 不靠画面推进）+ **「不要把这条自检写进逐格输出行」**。
- 测试新增一整个 `it`；回归守卫 `storyboard` 仍不含「页尾钩子」。

⚠️ **衔接旁白只放在分镜层，不动剧本层**：剧本场景头已给「地点 + 时间」，从剧本取材不算编造；
两层都写会口径打架（剧本层钩子仍归 §20）。

⚠️ **「只在断层处补」是防固定尾段的关键** ——「每页都要交代跨度」会立刻退化成每页挂同一句（同 §19 媒介质感锚的病）。

口径与改前/改后样例见 `docs/分镜叙事连贯-口径.md`；方案文档 §21。
