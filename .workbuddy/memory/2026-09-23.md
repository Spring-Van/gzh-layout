### 页签藏不住 + 右栏空白：根因是 `genPrompts[].text` 为 null（同日，已实机验证）

用户报「分镜/绘图切换后右栏空白、下拉菜单不关、切回资产 tab 两个内容同时显示」。
用 Electron + Playwright 加载**真实项目数据**复现成功（复现方法见 topics/local-debug.md）。

**根因**：`PanelPromptPanel` 提示词切换条的 `v-for` 里写了 `slot.text.trim()`，
而用户库里存着 `text: null`（中间态数据）：

```json
[{ "id":"cfe95909…", "text": null }, { "id":"38cd0b8e…", "text":"" }]
```

一条 null 就让**整个右栏渲染抛 TypeError → 空白**；且 Vue 的补丁一路 patch 下去，
子树抛错会让**父页面这次更新整体中断** → 于是 `v-show` 没应用（两个 tab 同时显示）、
浮层状态没更新（下拉菜单关不掉）。三个症状同源。

**修（两层 + 一个定位手段）**：
1. `utils/genPromptSlots.normalizeGenPromptSlot()`：读入时把 `text` 归一成字符串、开关补成 boolean、
   `uploadedRefs` 补成数组。`resolveActiveGenSlot` / `PanelPromptPanel.resetSlots` /
   `AssetVariantCard.resetSlots` 一律走它。**类型写的是 `text: string`，但库里可以违规，必须防御**。
2. 模板 `slot.text.trim()` → `(slot.text ?? '').trim()`（纵深防御）。
3. 新增 `components/common/TabPanel.vue`：页签互斥由**容器层**保证（`v-show` 不再写在子组件上），
   并用 `onErrorCaptured` 兜住子树渲染错误、就地降级成可读错误文案（`return false` 不向上冒泡）。
   接线：`LongProject.vue` 的资产/分镜页签各包一层；分镜右栏「分镜内容/绘画提示词」阶段区也包一层。
   **这个兜底是定位手段** —— 正是它把「不可见的渲染异常」变成屏幕上可读的报错，才定位到 null。

**实机验证（真实数据，「22」项目 13 镜）**：
- ① 分镜 tab：分镜内容显示、提示词面板已隐藏
- ② 切绘图：菜单正常关闭、绘画提示词区域**正常显示**、分镜内容已隐藏
- ③ 切资产 tab：绘图内容 `display:none`、只显示资产自己的工作台
