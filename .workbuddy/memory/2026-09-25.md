## 批量生成绘画提示词弹窗默认模板不选中修复（AssetPromptGenerateModal.vue）

- 现象：一次性发送下 select 显示「选择模板」占位、输入框空。
- 根因：打开时 `if (!templateId.value)` 只判空不校验存在性——`assetGenConfig.promptTemplateId`（或组件残留 id）指向已删除模板时失效 id 顶掉默认选中，`builtPromptFor()` find 不到返回空串；且无模板列表变化的兜底 watch（PanelPromptGenerateModal 有、这边没有）。
- 修复：新增 `pickValidId()`（当前有效→沿用；记忆有效→用记忆；否则第一个），modelId/templateId 打开时统一走三级回填；补 `watch(props.templates)` 失效回退第一个。vue-tsc 通过。
