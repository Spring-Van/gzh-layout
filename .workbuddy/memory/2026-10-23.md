## 排障：`pnpm run dev` 起不来（electron 二进制被 allowBuilds 断掉）

19:08 有一次 node_modules 重新链接，之后启动失败。两个独立原因：

1. **主因：Electron 二进制缺失**。`pnpm-workspace.yaml` 里 `allowBuilds` 把 electron/esbuild/sharp 全设成 `false`，
   pnpm install 时跳过 electron 的 postinstall → `node_modules/.pnpm/electron@30.5.1*/node_modules/electron/` 下
   **没有 `dist/` 也没有 `path.txt`** → `require('electron')` 抛 `Electron failed to install correctly`。
   已改回 `allowBuilds: electron/esbuild/sharp: true`（附注释），并手动跑 `node install.js` 补齐二进制（下载约 7 分钟）。
2. **环境变量污染**：本机 agent shell 带 `ELECTRON_RUN_AS_NODE=1`（WorkBuddy 自己注入，用户级注册表里没有），
   Electron 退化成 Node，报 `does not provide an export named 'BrowserWindow'` + `Node.js v20.16.0`。
   在 agent 里起应用必须 `env -u ELECTRON_RUN_AS_NODE`。

判定口诀：终端只吐 `$ vite` 后无输出/报 `failed to install correctly` → 查二进制；报 `BrowserWindow` 导出不存在 → 查环境变量。
