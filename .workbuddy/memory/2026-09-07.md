## 漫画 Tab 按项目多开 + 项目名标题(设计方案,未动代码)

- 用户要求:①Tab 标题显示项目名;②漫画 Tab 按项目多开。确认现状:漫画 Tab 是单例(所有 /comic/* 路由 meta.tab.key='comic')。
- 方案文档:`docs/漫画Tab按项目多开设计方案.md`。核心设计:
  - 动态归并键 resolveMatchKey:带 :projectId 的 7 条子路由 matchKey=comic:p:${projectId},项目列表保持 'comic' 单例;
  - TabItem.label(项目名)持久化,标题=label?"项目名 · 子页面":"子页面",各子页面 setup 同步捕获 matchKey、项目加载后 setLabel;
  - 关键技术点:keep-alive include 按组件名过滤,多实例靠"每个 Tab 唯一组件名的包装组件"(vben admin 同款,utils/tabComponent.ts 工厂+Map 缓存),关 Tab 移出 include 即精确驱逐实例并触发 unmount flush 落盘;TabItem.visited 字段废弃,由 cacheName(matchKey 纯函数推导)取代;
  - 明确排除:同 Tab 内子页面保活(靠 300ms 防抖存盘兜底,与现状一致)、关闭确认弹窗。
- PageEditor 已有 usePageEditorPersistence(300ms 防抖 IPC 落盘+onBeforeUnmount flush),关 Tab 数据安全有兜底。
- 待用户确认方案后实施(约 7 个文件,净增 80~120 行)。
