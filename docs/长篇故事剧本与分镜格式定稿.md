# 长篇故事：漫画剧本 / 分镜 格式定稿（v3）

> **v3 修订一句话**：剧本不变；**分镜不再挤成一行**，改为「**一页一块、一格一行**」的页块格式。
> 它读起来就是一份漫画脚本，人看得懂、改得动；模型也不容易漏格、漏分隔符。
> **台词一律写明说话人，并把台词 / 旁白正文用【】括起来**（`说话人：【台词】`），与剧本原句逐字一致。
> 概念仍是 **一个分镜 = 一张竖屏漫画图 = 一页**，一页内 1~4 格（格 = 图内的分格）。
> 本文档只管「生成什么样的剧本、什么样的分镜」，不含代码改动。
>
> **v3.1 增量（2026-09-10）**：分镜的**台词 / 旁白正文**加【】包裹（`说话人：【台词】` / `旁白：【文字】`），让台词行与画面行在纯文本里一眼可分；`【】` 仅用于「台词正文」与「格首镜头」，画面行内不出现。**剧本层不变**（剧本仍是 `说话人：台词`）。

## 0. 一句话结论

| 层 | 单位 | 格式 |
|----|------|------|
| 剧本 | 场景 | `## 场景 N` + 8 字段（地点/人物/剧情/动作/情绪/对白/本场目的/预估页数）——**不变** |
| **分镜** | **一张漫画图 = 一页**（1~4 格） | **`## 分镜 N · X格` 起一块；一格一行 `①【镜头】画面`；台词另起一行 `说话人：【台词】`（正文带【】、说话人在外）** |
| 画面描述 | 一格 / 一整页 | 自包含生图提示词（分格结构、分割线、人物占比、浅景深、光线、气泡位置…） |

三层职责边界：

- **剧本**决定"这一章每一场戏怎么演"；
- **分镜**决定"这一页里有几格、每格是什么镜头、画什么、说什么"——**内容与节奏**；
- **画面描述**决定"这一格具体怎么画"——**视觉参数**（6 种分格结构 + 13 种排版变体 + 人物占比铁律 + 浅景深铁律 + R13/R14 视角一致性 + 气泡规范）。

## 1. 漫画剧本（格式定稿，沿用 v1/v2，仅补强说话人规则）

### 1.1 结构

```markdown
## 场景 N 地点·时间
- 地点：这个场景在哪
- 人物：本场出场人物
- 剧情：本场发生什么（3~5 句，按发生顺序）
- 动作：关键动作 / 走位 / 画面重点（可多条）
- 情绪：情绪基调与转折（谁：怎么变）
- 对白：最终台词，一人一行，「说话人：台词」
- 旁白：无人称叙述（可省略；没有就不写这一行）
- 本场目的：铺垫 / 推进 / 转折 / 收束 + 一句话
- 预估页数：4
```

### 1.2 完整示例（示例故事 · 场景 1）

```markdown
## 场景 1 室内·傍晚
- 地点：家中室内
- 人物：角色B、角色A、关键道具「道具名」（关键道具级角色）
- 剧情：角色B提出关键道具已损坏、无法复原，角色A当场冷脸维护它；角色B平静地提出处理掉，
  角色A先反对、再转而哀求把它留在封闭容器里；角色B沉默一分钟后勉强让步。
- 动作：角色A把关键道具护到身后、指节收紧、咬牙攥拳、伸手想拉她又缩回；角色B垂眼、别开视线、捏衣角
- 情绪：角色A 焦躁维护 → 急切恳求；角色B 隐忍 → 平静 → 勉强让步
- 对白：
  角色A：角色B，你怎么能那么残忍？破坏了它的关键部分，跟要了它的命有什么区别？
  角色A：你让它以后怎么办？你怎么能说出这种话？
  角色B：我也觉得很残忍。那还是处理掉吧。
  角色B：总不能为了留着它，把它关起来吧。
  角色A：对！我们可以找个容器把它养起来。
  角色B：开放的容器还是不安全。万一盖子没盖紧呢？角色C会去碰的。
  角色A：那就买个封闭的！求求你了，咱们留下它吧？你放心，我绝对不会让它伤害到你们的！
  角色B：行吧。不过容器我来选。
- 本场目的：推进——暴露角色A对关键道具的异常执念，为后续冲突埋线
- 预估页数：22
```

### 1.3 剧本写作规则

1. 只改编原文已明确的内容，不新增事件、不补写设定；
2. 对白写成**最终上台词的版本**，**每一行都必须带说话人**（`说话人：台词`）——分镜会原样搬运，一字不改；
3. 大段心理描写外化为动作 + 表情 + 旁白，不保留成坨的内心戏；角色心理活动若必须保留，写成 `说话人（心声）：文字`；
4. 场景 = 同一时间 + 同一地点；闪回、时间跳跃单独成场景并在标题标注；
5. 一章建议 10~25 页（"页"= 一张图）；预估页数是锚点，分镜可浮动 ±20%；
6. 剧本不写"分格"——分格属于分镜与画面描述层。

> 注：「预估页数」里的"页" = 一张漫画图 = 一个分镜，不是"一格"。

## 2. 分镜（格式定稿 v3）——一页一块，一格一行

### 2.1 为什么放弃"一行一图"

v2 把整页压成一行：`镜头｜画面｜台词 ‖ 镜头｜画面｜台词`。单格页还行，**一到多格就塌**：

| 维度 | v2 一行一图 | **v3 页块格式（采用）** |
|------|------------|------------------------|
| 一行是什么 | 一整页（含 1~4 格） | 一个元素（页头 / 一格 / 一句台词） |
| 多格页可读性 | 差：格被 `‖` 挤在一行，肉眼难辨 | 好：格逐行排列，结构一眼看清 |
| 手改成本 | 高：要数 `‖` 在哪儿 | 低：改哪格就编辑哪行 |
| 模型输出稳定性 | 长行易错位、漏 `‖`、漏格 | 分行清晰，漏格/多格一眼可查 |
| 解析复杂度 | 需按 `‖` 二次切分，容错难 | 逐行状态机，规则极简 |
| 与生图对接 | 需要再拆 | 一格一天然对应一个画面单元 / 一个气泡 |
| 专业对照 | 无对应格式 | 接近美漫 full script（PAGE / PANEL 分块） |

### 2.2 页块格式规范

```
## 分镜 1 · 单格
①【中景】角色A把关键道具护到身后，冷脸盯着角色B。
角色A：【角色B，你怎么能那么残忍？】

## 分镜 2 · 双格
①【近景】角色A指节收紧，关键道具缠上小臂。
角色A：【破坏了它的关键部分，跟要了它的命有什么区别？】
②【中景】角色B站在沙发边，眉头拧起。
```

**三条语法（也是解析规则）：**

1. `## 分镜 N · X格` —— 起一页（一块）。`N` 与 `X格` 只供阅读，**解析以出现顺序为准**，系统按顺位自动纠正；
2. `①【镜头】画面` —— 起一格。`①`~`④` 随格序递增，`【】` 内是镜头类型；
3. `说话人：【台词】` / `旁白：【文字】` —— 台词 / 旁白正文用【】括起、说话人写在【】外，属于**它上方最近的格**；这一格没有台词就不写这一行。

> 空行只用来分隔页块；同一页内不插空行。台词行也可以接到格行末尾用 `｜` 分隔（`①【近景】画面｜角色A：【台词】`），解析器两种都认，但**默认输出用独立成行**，更好读、更好改。
> `【】` 全篇只承担两个作用：**格行开头的镜头**、**台词 / 旁白正文的包裹**。画面行里不要出现 `【】`。解析时台词 / 旁白正文的 `【】` 会被剥掉入库，序列化时再补回——`【】` 是排版记号，不进数据。

### 2.3 字段规范

| 元素 | 写法 | 内容 | 取值 / 字数 |
|------|------|------|------------|
| **页头** | `## 分镜 N · X格` | 页号 + 格数（1~4） | `X格` = 单格 / 双格 / 三格 / 四格 |
| **镜头** | `【】` 内 | 这一格的镜头类型 | 7 选 1：`远景` `中景` `近景` `特写` `POV` `过肩` `仰拍`（**必填**） |
| **画面** | `【】` 后 | 这一格画面上能看到什么 | 谁 + 在做什么 + 神态/情绪，15~40 字 |
| **台词** | 独立行 | `说话人：【台词】` | 对白，正文写在【】内、说话人在外；≤20 字（单格满版 ≤30 字） |
| **心声** | 独立行 | `说话人（心声）：【台词】` | 角色内心独白，气泡样式不同于对白 |
| **画外** | 独立行 | `说话人（画外）：【台词】` | 说话人不在该格画面内（听者反应镜 / 画外音） |
| **旁白** | 独立行 | `旁白：【文字】` | 无人称旁白框，不带说话人 |

`镜头` 段的意义：它是画面描述层的**输入锚点**——人物占比（远景 <20% / 中景 40-60% / 近景 60-80% / 特写 >80%）、景别、景深等级、焦段都由它决定。写在分镜层，画面描述层就不必猜。

---

### 2.4 台词归属规则（一次讲清）

> **能不能不写说话人？不能。** 说话人决定三件事：① 气泡**挂在谁头上**；② 谁要**张嘴 / 给表情**；③ 绑定**哪个角色资产**。不写，竖屏成图时气泡就会挂到错误角色的脸上。

1. **台词行写在它所属那一格的下面**——上面最近的 `①`~`④` 就是它的格；
2. **每句台词必须带说话人**：`说话人：【台词】`（正文写在【】内、说话人在外）。台词文字就是剧本里的原句，**直接搬运、连标点都不改**；
3. **一格最多一句台词**（一个说话人）；两个角色说话就拆成两格；
4. 说话人**不在该格画面里**时（听者反应镜、画外音），标 `说话人（画外）：【台词】`；
5. 角色**心里想的**，标 `说话人（心声）：【台词】`——心声不要求说话人出现在画面里；
6. **没有人称的旁白**写 `旁白：【文字】`（不带说话人）；
7. 说话人名字与**资产库角色名一致**，方便自动绑定；剧本里怎么称呼，分镜里就怎么称呼。

**归属判定示例：**

```
## 分镜 3 · 双格
①【过肩】角色A俯身逼近。
角色A：你让它以后怎么办？        ← 属于 ①（说话人在 ① 画面内）
②【近景】角色B别开视线，嘴唇抿紧。

## 分镜 4 · 单格
①【特写】角色B睫毛低垂，张了张嘴又把话咽回去。
角色A（画外）：你怎么能说出这种话？          ← 角色B的反应镜，说话人在画面外
```

### 2.5 分格规则（对齐分格结构库）

| 规则 | 内容 |
|------|------|
| 一页格数 | 1~4 格（3:4 竖屏承载力）；5 格以上只留给"不规则拼贴"极端页 |
| **一格 = 一个信息单元** | 一个镜头类型 + 一个情绪焦点 + 一个动作/反应；**不要在一格里塞两个叙事节点**（结构库铁律 3） |
| 一格一个说话人 | 一格里只放一个角色的台词，且**台词行必须写明说话人**；两个角色对话 → 拆两格（结构库"一格最多 2 气泡"的简化执行） |
| 台词字数 | **每格 ≤ 20 字**；单格满版页 ≤ 30 字；旁白同限 |
| 主视觉格 | 页内必须唯一主格（情绪焦点）；分镜不必指定，画面描述层按"主格最大"处理 |
| 格数多样性 | 全篇 20~30% 用**单格满版或 3~4 格**，避免通篇都是上下双格（对应结构库"排版多样性"要求） |
| 视角一致性 | 面对面时**不要在同一页里让两个人各占一格且都露正脸**（R13/R14 由画面描述层校验，分镜层只需保证内容不矛盾） |

### 2.6 什么算"一格"（分格判定）

| 算一格 | 不算一格（并进同格或删） |
|--------|------------------------|
| 一次动作 / 一次反应 | 同一动作的重复描述 |
| 一句关键台词（≤20 字） | 语气词、无信息量的应答 |
| 一次表情 / 情绪转折 | 纯环境描写（并进有人的格，或作单格满版呼吸页） |
| 关键道具 / 信息首次出现（可作小格特写） | 无法画面化的心理独白（改写为心声或旁白） |
| POV 内容（手机屏、窗外、书页） | 把"角色看屏幕"和"屏幕内容"塞进同一格（必须拆格，R13） |

### 2.8 分镜写作规则

1. 一页一块，一格一行；页块之间空一行，页内不空行；
2. 一页 1~4 格，一格一个信息单元，不要塞两个叙事节点；
3. 每格必写「镜头」，取 7 种标准镜头之一；画面 15~40 字；台词 ≤20 字（单格满版 ≤30 字）；
4. **每句台词都带说话人**（`说话人：台词`），从剧本原样搬运、不改写；剧本与原文冲突时以剧本为准；
5. 说话人不在画面内标 `（画外）`；角色内心活动标 `（心声）`；无人称叙述写 `旁白：`；
6. 关键动作/情绪转折可给独立页或独立格；重要道具/信息首次出现可给小格特写；
7. 保持人物空间关系连续（上一格在左，下一格不要跳到右）；
8. 全篇 20~30% 用非"上下双格"的格数组合（单格满版 / 3~4 格），避免通篇一个节奏。

## 3. 剧本 → 分镜 的对应关系

| 剧本字段 | 落到分镜哪里 |
|---------|-------------|
| 地点 / 情绪 | 画面段的场景与神态（不明写，体现在描述里） |
| 剧情 | 页的数量与顺序（一句剧情 → 1~4 页） |
| 动作 | 画面段的动作主体，优先独立成页/格 |
| **对白** | 台词行，**连同说话人一起原样搬运**；超 20 字拆成多格或多页，拆开后每句仍带说话人 |
| 本场目的 | 不进入分镜，用于筛页（对目的无贡献的页删掉） |
| 预估页数 | 页数锚点（±20%） |

**格数与剧情密度对照**：

| 剧情情况 | 建议格数 |
|---------|---------|
| 一句台词 / 一个动作 | 单格满版 |
| 对话来回（问 → 答） | 上下双格 / 左右双格 |
| 对峙、对比、双视角 | 左右双格 |
| 铺垫 → 发展 → 爆点 | 三格递进 |
| 情绪核心 + 细节补充（表情/手部/道具） | 不规则主从格 |
| 爆点、反转、结尾 | 单格满版（人物占比拉高） |

## 4. 可直接粘贴的模板（系统设置 → 提示词模板）

### 4.1 剧本 · 推荐模板

```
你是一名资深的条漫编剧。请把当前章节改编成漫画剧本，回答"这一章每一场戏怎么演"。

【改编原则】
- 只改编原文已明确的内容，不新增事件、不补写原文没有的设定。
- 按场景组织：场景 = 同一时间 + 同一地点的连续剧情；闪回、时间跳跃单独成场景并在标题标注。
- 对白写成最终上台词的版本：口语化、贴合人物身份，每行都必须带说话人（说话人：台词）。
  分镜阶段会原样搬运，不再改写，所以说话人一个字都不能省。
- 角色内心活动写成「说话人（心声）：文字」；无法上台词的叙述写成「旁白：文字」。
- 删掉无法画面化的纯心理描写与重复叙述，改用动作、表情、对白、旁白外化情绪。
- 关键转折、关键信息必须保留；不要写成分章小说。

【篇幅节奏】
- 按"页"（= 一张漫画图）估算每场信息量，写入「预估页数」；一章建议 10~25 页。
- 一个动作 / 一句关键台词 / 一次情绪变化 ≈ 一页。
- 不要写分格——分格由分镜与画面描述环节负责。

【输出内容】
每个场景写明：地点、人物、剧情、动作、情绪、对白、本场目的、预估页数。

【章节原文】
{{章节原文}}

【原文分析】
{{原文分析}}
```

```
只输出中文 Markdown，不要解释、代码块或 JSON。
用 ## 场景 N 地点·时间 组织每个场景，场景内用「- 属性名：内容」逐行写明：
地点、人物、剧情、动作、情绪、对白、本场目的、预估页数。
```

### 4.3 分镜 · 推荐模板（v3）

```
你是一名条漫分镜师。请把下面的漫画剧本拆成一页页漫画分镜。
一个分镜 = 一张竖屏漫画图 = 一页；一页内可以有 1~4 格。

【分页原则】
- 先把剧情切成"页"（一页承载一个完整节拍），再决定这一页内分几格。
- 一页 1~4 格；同一页内的若干格属于同一节拍的不同瞬间（对话来回、动作连拍、主画面+细节）。
- 全篇约 20%~30% 的页使用单格满版或 3~4 格，避免通篇都是上下双格。
- 保留呼吸页：纯画面页（无台词）或短旁白页，每章 3~6 页，用来控制节奏。

【分格原则】
- 一格 = 一个信息单元 = 一个镜头类型 + 一个情绪焦点 + 一个动作/反应；不要在一格里塞两个叙事节点。
- 一格里只放一个角色的台词；两个角色对话就拆成两格。
- 角色"看手机/电视/书/窗外，同时读者也要看到内容"时，必须拆成两格（一格角色反应 + 一格主观 POV）。
- 面对面交谈时，不要在同一页里让两个人各占一格且都露正脸。

【每一页怎么写】
- 页面标题：## 分镜 N · 单格 / 双格 / 三格 / 四格（N 从 1 递增）。
- 每一格单独一行，以 ① ② ③ ④ 开头，紧跟【镜头】，再写画面。
- 台词另起一行，写在它所属格的下面，属于它上面最近的那一格；说话人必须写，且与剧本完全一致。
- 这一格没有台词就不写这一行。

【台词行怎么写】（台词 / 旁白正文一律用【】括起来，说话人写在【】外面）
- 对白：说话人：【台词】　例　角色A：【破坏了它的关键部分，跟要了它的命有什么区别？】
- 内心独白：说话人（心声）：【台词】
- 说话人不在本格画面内：说话人（画外）：【台词】
- 无人称旁白：旁白：【文字】

【每格字段】
- 镜头：从 远景 / 中景 / 近景 / 特写 / POV / 过肩 / 仰拍 中选一个（必填）。
- 画面：只写这一格画面上能看到的东西——谁、在做什么、什么神态或情绪，15~40 字。
- 台词：必须写明说话人、正文用【】括起；不超过 20 字（单格满版不超过 30 字），超过必须拆成多格或多页。
- 【】只用于框住台词 / 旁白正文与每格格首的【镜头】，画面行里不要出现【】。
- 不写绘画风格、颜色、光影、人物占比、景深、分格结构、气泡位置——这些由画面描述环节按规则库处理。

【漫画剧本】
{{漫画剧本}}

【原文分析】
{{原文分析}}
```

## 6. 已确认（全部落定）

1. **格号 ①②③④ 保留** —— 一页几格一目了然，模型也不易漏格。
2. **「镜头」段每格必填** —— 它是人物占比 / 景深 / 焦段的推导锚点。
3. **台词必须写明说话人** —— `说话人：【台词】`（正文带【】、说话人在外），与剧本原句逐字一致，分镜直接搬运（见 2.4）。
4. **新增两种台词标记** —— `（心声）` 内心独白、`（画外）` 说话人不在画面内；无人称叙述用 `旁白：【…】`。
5. **页头固定用 `## 分镜 N · X格`** —— 与现有解析器 `## 分镜 N` 正则兼容，页头识别无需改动。
6. **台词行默认独立成行** —— 好读好改；解析器同时兼容 `画面｜说话人：台词` 的行内写法与 v2 的 `‖` 分格。
7. **台词 / 旁白正文用【】括起（v3.1）** —— 只作用于分镜层，`【】` 在行首时仍是镜头；**入库去括、出库带括**，页级 `dialogue` / `narration` 与画面描述提示词不受影响。
