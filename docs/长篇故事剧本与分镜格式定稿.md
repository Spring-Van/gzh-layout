# 长篇故事：漫画剧本 / 分镜 格式定稿（v5）

> **v5 修订一句话（2026-09-19）**：**全链路统一 Markdown**——分镜放弃 v4 专用符号（`【第X格】` / `「字段名」：`），
> 改用纯 Markdown 语法：格用 `### 第X格` 标题，字段用 `- 字段名：内容` 列表行；页头 `## 分镜 N · X格` 不变。
> 同批统一：资产绘画提示词逐条改为 `## 资产名｜状态名` 标题 + 正文；画面描述整章分段标记改为 `## 分镜 N`。
> 解析器向下兼容全部历史形态（v4 符号 / v3 页块 / v2 行内分格），旧数据与旧导入文本不受影响。
>
> **v4 修订一句话**：剧本不变；**分镜改用「符号规则」**——分镜格用 `【第X格】`，内容标题用 `「XXX」`，冒号后写具体内容。
> 一格不再只有「镜头 + 画面 + 一句台词」，而是**逐字段展开**：景别 / 镜头 / 画面 / 人物 / 动作 / 表情 / 台词 / 心声 / 画外 / 旁白 / 音效 / 光效 / 备注。
> 概念仍是 **一个分镜 = 一张竖屏漫画图 = 一页**，一页内 1~4 格（格 = 图内的分格）。
> 本文档只管「生成什么样的剧本、什么样的分镜」，不含代码改动。
>
> **v4 增量（2026-09-11）**：句型从 v3 的「`①【镜头】画面` + `说话人：【台词】`」换成
> 「`【第X格】` + `「字段名」：内容`」。理由：v3 只有三个槽位（景别、画面、台词），
> 运镜、人物、动作、表情、音效、光效无处安放，只能塞进「画面」里挤成一坨；
> 逐字段展开后既能写清楚，也便于解析器把每个字段单独取出来喂给下游。
> **剧本层不变**（剧本仍是 `## 场景 N` + `- 属性名：内容`）。

## 0. 一句话结论

| 层 | 单位 | 格式 |
|----|------|------|
| 剧本 | 场景 | `## 场景 N` + 8 字段（地点/人物/剧情/动作/情绪/对白/本场目的/预估页数）——**不变** |
| **分镜** | **一张漫画图 = 一页**（1~4 格） | **`## 分镜 N · X格` 起一块；格用 `### 第X格` 标题起头，逐行写 `- 字段名：内容`（13 字段）** |
| 画面描述 | 一格 / 一整页 | 自包含生图提示词（分格结构、分割线、人物占比、浅景深、光线、气泡位置…） |

三层职责边界：

- **剧本**决定"这一章每一场戏怎么演"；
- **分镜**决定"这一页里有几格、每格是什么镜头、画什么、说什么"——**内容与节奏**；
- **画面描述**决定"这一格具体怎么画"——**视觉参数**（6 种分格结构 + 13 种排版变体 + 人物占比铁律 + 浅景深铁律 + R13/R14 视角一致性 + 气泡规范）。

## 1. 漫画剧本（格式定稿，沿用 v1/v2，仅补强说话人规则）

### 1.1 结构

```markdown
## 场景 N 地点·时间
- 地点：这个场景在哪
- 人物：本场出场人物
- 剧情：本场发生什么（3~5 句，按发生顺序）
- 动作：关键动作 / 走位 / 画面重点（可多条）
- 情绪：情绪基调与转折（谁：怎么变）
- 对白：最终台词，一人一行，「说话人：台词」
- 旁白：无人称叙述（可省略；没有就不写这一行）
- 本场目的：铺垫 / 推进 / 转折 / 收束 + 一句话
- 预估页数：4
```

### 1.2 完整示例（示例故事 · 场景 1）

```markdown
## 场景 1 室内·傍晚
- 地点：家中室内
- 人物：角色B、角色A、关键道具「道具名」（关键道具级角色）
- 剧情：角色B提出关键道具已损坏、无法复原，角色A当场冷脸维护它；角色B平静地提出处理掉，
  角色A先反对、再转而哀求把它留在封闭容器里；角色B沉默一分钟后勉强让步。
- 动作：角色A把关键道具护到身后、指节收紧、咬牙攥拳、伸手想拉她又缩回；角色B垂眼、别开视线、捏衣角
- 情绪：角色A 焦躁维护 → 急切恳求；角色B 隐忍 → 平静 → 勉强让步
- 对白：
  角色A：角色B，你怎么能那么残忍？破坏了它的关键部分，跟要了它的命有什么区别？
  角色A：你让它以后怎么办？你怎么能说出这种话？
  角色B：我也觉得很残忍。那还是处理掉吧。
  角色B：总不能为了留着它，把它关起来吧。
  角色A：对！我们可以找个容器把它养起来。
  角色B：开放的容器还是不安全。万一盖子没盖紧呢？角色C会去碰的。
  角色A：那就买个封闭的！求求你了，咱们留下它吧？你放心，我绝对不会让它伤害到你们的！
  角色B：行吧。不过容器我来选。
- 本场目的：推进——暴露角色A对关键道具的异常执念，为后续冲突埋线
- 预估页数：22
```

### 1.3 剧本写作规则

1. 只改编原文已明确的内容，不新增事件、不补写设定；
2. 对白写成**最终上台词的版本**，**每一行都必须带说话人**（`说话人：台词`）——分镜会原样搬运，一字不改；
3. 大段心理描写外化为动作 + 表情 + 旁白，不保留成坨的内心戏；角色心理活动若必须保留，写成 `说话人（心声）：文字`；
4. 场景 = 同一时间 + 同一地点；闪回、时间跳跃单独成场景并在标题标注；
5. 一章建议 10~25 页（"页"= 一张图）；预估页数是锚点，分镜可浮动 ±20%；
6. 剧本不写"分格"——分格属于分镜与画面描述层。

> 注：「预估页数」里的"页" = 一张漫画图 = 一个分镜，不是"一格"。

## 2. 分镜（格式定稿 v4）——符号规则：格用【第X格】，字段用「」

### 2.1 为什么放弃"一行一图"

v2 把整页压成一行：`镜头｜画面｜台词 ‖ 镜头｜画面｜台词`。单格页还行，**一到多格就塌**：

| 维度 | v2 一行一图 | **v4 页块格式（采用）** |
|------|------------|------------------------|
| 一行是什么 | 一整页（含 1~4 格） | 一个元素（页头 / 格标题 / 一个字段） |
| 多格页可读性 | 差：格被 `‖` 挤在一行，肉眼难辨 | 好：格逐行排列、字段逐行列出，结构一眼看清 |
| 信息承载力 | 3 个槽位（景别 / 画面 / 台词），其余全挤进"画面" | **13 个字段**各占一行，运镜/人物/动作/表情/音效/光效各有归处 |
| 手改成本 | 高：要数 `‖` 在哪儿 | 低：改哪个字段就编辑哪行 |
| 模型输出稳定性 | 长行易错位、漏 `‖`、漏格 | 分行清晰，漏格/漏字段一眼可查 |
| 解析复杂度 | 需按 `‖` 二次切分，容错难 | 逐行状态机，规则极简 |
| 与生图对接 | 需要再拆 | 一个字段一天然对应下游的一个输入（景别 → 占比/景深、光效 → 光线） |
| 专业对照 | 无对应格式 | 接近日式条漫分镜表（面板 × 字段） |

### 2.2 页块格式规范（v5 Markdown）

```
## 分镜 1 · 双格
### 第1格
- 景别：近景转特写
- 镜头：从角色A侧脸下摇至小臂
- 画面：角色A的手臂占前景，指节收紧，青筋凸起。关键道具的尾端从画外缠上小臂，表面压进皮肤。
- 人物：角色A
- 动作：指节收紧，手臂绷紧，关键道具缠上小臂。
- 表情：侧脸冷硬，眼神压着怒意，下颌绷紧。
- 台词：角色A：“破坏了它的关键部分，跟要了它的命有什么区别？”
- 音效：沙沙——表面摩擦。
- 光效：暖黄顶灯，背景压暗，手臂局部高光。

### 第2格
- 景别：中景
- 镜头：平视，角色B站在室内靠背前，前景可带角色A手臂虚影。
- 画面：角色B一手扶住靠背，身体微僵，视线看向画外角色A方向。背景顶灯突然熄灭，画面下半部迅速压黑。
- 人物：角色B
- 动作：手扶靠背，身体微僵，视线投向画外。
- 表情：眉头拧起，嘴唇微张，眼神警惕。
- 心声：角色B：“他到底想干什么……”
- 旁白：夜色压下来，屋里的灯忽然灭了。
- 音效：啪——嗡——
- 光效：暖灯骤灭，冷蓝夜光。
- 备注：灯灭必须画出来：灯泡“啪”地熄灭，画面压黑，不要只靠旁白交代。
```

**四条语法（也是解析规则）：**

1. `## 分镜 N · X格` —— 起一页（一块）。`N` 与 `X格` 只供阅读，**解析以出现顺序为准**，系统按顺位自动纠正；`X格` 会显示在左栏列表上；
2. `### 第X格` —— 起一格（Markdown 标题行）。`X` 从 1 递增，可以同行续写内容，但**默认独立成行**；
3. `- 字段名：内容` —— 写这一格的某个字段（Markdown 列表行），一行一个字段，属于**它上方最近的 `### 第X格`**；
4. **没有内容的字段整行省略**，不要写空字段。

> 空行只用来分隔页块（也可不空）。字段行必须以 `- ` 起头——列表行是格字段的唯一形态。
> 解析时字段值会按字段名分流入库（台词类会把「说话人：」与引号拆开），序列化时再拼回，所见即所得。
>
> **v4 历史示例兼容说明**：本文档 2.7 等处的示例页仍以 v4 符号（`【第X格】` / `「字段」：`）书写，
> 解析器照常识别；新产出一律按 v5 Markdown 写。两种符号可按 `【第X格】→### 第X格`、`「字段」：→- 字段：` 机械换算。

### 2.3 字段规范

| 顺序 | 字段 | 内容 | 取值 / 字数 |
|------|------|------|------------|
| 1 | **景别** | 这一格的景别 | 7 选 1：`远景` `中景` `近景` `特写` `POV` `过肩` `仰拍`（**必填**，可写 `近景转特写` 这种运镜式景别） |
| 2 | **镜头** | 机位与运镜 | 如 `平视` / `俯拍` / `从侧脸下摇至小臂` / `前景带另一角色虚影`（可省略） |
| 3 | **画面** | 这一格画面上能看到什么 | 构图 + 人物位置 + 动作 + 环境 + 关键细节，30~80 字 |
| 4 | **人物** | 本格画面内出现的角色 | 多个用 `、` 分隔；**不在画面内的说话人不写在这里** |
| 5 | **动作** | 本格的肢体动作 | 10~25 字 |
| 6 | **表情** | 本格的神态与情绪 | 10~25 字 |
| 7~10 | **台词 / 心声 / 画外 / 旁白** | 本格的说话内容 | 四选一，同一格**最多出现一个**；写法见 2.4 |
| 11 | **音效** | 本格的声音 | 如 `沙沙——表面摩擦`；没有就不写 |
| 12 | **光效** | 本格的光线与明暗关系 | 如 `暖黄顶灯，背景压暗，手臂局部高光`；没有就不写 |
| 13 | **备注** | 画面上必须画出来的关键点 | 如 `灯灭必须画出来`；没有就不写 |

`景别` 段的意义：它是画面描述层的**输入锚点**——人物占比（远景 <20% / 中景 40-60% / 近景 60-80% / 特写 >80%）、景别、景深等级、焦段都由它决定。写在分镜层，画面描述层就不必猜。

> 字段顺序固定为：景别 → 镜头 → 画面 → 人物 → 动作 → 表情 → 台词/心声/画外/旁白 → 音效 → 光效 → 备注。解析器按字段名识别、不依赖顺序，但**输出时按此顺序**，便于人读。

### 2.4 台词归属规则（一次讲清）

> **能不能不写说话人？不能。** 说话人决定三件事：① 气泡**挂在谁头上**；② 谁要**张嘴 / 给表情**；③ 绑定**哪个角色资产**。不写，竖屏成图时气泡就会挂到错误角色的脸上。

1. **台词类字段写在它所属那一格里**——上面最近的 `【第X格】` 就是它的格；
2. **每句台词必须带说话人**：`「台词」：说话人：“台词”`。台词文字就是剧本里的原句，**直接搬运、连标点都不改**；引号用中文引号 `“”`；
3. **同一格最多一句台词**（`台词` / `心声` / `画外` / `旁白` 只出现其中一个）；两个角色说话就拆成两格；
4. 说话人**不在该格画面里**时（听者反应镜、画外音），用 `「画外」`；
5. 角色**心里想的**，用 `「心声」`——心声不要求说话人出现在画面里；
6. **没有人称的旁白**用 `「旁白」`，**不带说话人**：`「旁白」：夜色压下来，屋里的灯忽然灭了。`；
7. 说话人名字与**资产库角色名一致**，方便自动绑定；剧本里怎么称呼，分镜里就怎么称呼；
8. `「人物」` 字段与台词说话人是两回事：`「人物」`写**画面里出现的人**，`「画外」`的说话人**恰恰不在画面里**。

**归属判定示例：**

```
## 分镜 3 · 双格
【第1格】
「景别」：过肩
「画面」：角色A俯身逼近。
「人物」：角色A
「台词」：角色A：“你让它以后怎么办？”        ← 说话人就在本格画面里
【第2格】
「景别」：近景
「画面」：角色B别开视线，嘴唇抿紧。
「人物」：角色B

## 分镜 4 · 单格
【第1格】
「景别」：特写
「画面」：角色B睫毛低垂，张了张嘴又把话咽回去。
「人物」：角色B
「画外」：角色A：“你怎么能说出这种话？”      ← 角色B的反应镜，说话人不在画面里
```

### 2.5 分格规则（对齐分格结构库）

| 规则 | 内容 |
|------|------|
| 一页格数 | 1~4 格（3:4 竖屏承载力）；5 格以上只留给"不规则拼贴"极端页 |
| **一格 = 一个信息单元** | 一个镜头类型 + 一个情绪焦点 + 一个动作/反应；**不要在一格里塞两个叙事节点**（结构库铁律 3） |
| 一格一个说话人 | 一格里只放一个角色的台词，且**台词行必须写明说话人**；两个角色对话 → 拆两格（结构库"一格最多 2 气泡"的简化执行） |
| 台词字数 | **每格 ≤ 20 字**；单格满版页 ≤ 30 字；旁白同限 |
| 主视觉格 | 页内必须唯一主格（情绪焦点）；分镜不必指定，画面描述层按"主格最大"处理 |
| 格数多样性 | 全篇 20~30% 用**单格满版或 3~4 格**，避免通篇都是上下双格（对应结构库"排版多样性"要求） |
| 视角一致性 | 面对面时**不要在同一页里让两个人各占一格且都露正脸**（R13/R14 由画面描述层校验，分镜层只需保证内容不矛盾） |

### 2.6 什么算"一格"（分格判定）

| 算一格 | 不算一格（并进同格或删） |
|--------|------------------------|
| 一次动作 / 一次反应 | 同一动作的重复描述 |
| 一句关键台词（≤20 字） | 语气词、无信息量的应答 |
| 一次表情 / 情绪转折 | 纯环境描写（并进有人的格，或作单格满版呼吸页） |
| 关键道具 / 信息首次出现（可作小格特写） | 无法画面化的心理独白（改写为心声或旁白） |
| POV 内容（手机屏、窗外、书页） | 把"角色看屏幕"和"屏幕内容"塞进同一格（必须拆格，R13） |

### 2.8 分镜写作规则

1. 一页一块（`## 分镜 N · X格`），一格一段（`【第X格】` + 若干 `「字段名」：内容`）；页块之间空一行；
2. 一页 1~4 格，一格一个信息单元，不要塞两个叙事节点；
3. 每格必写 `「景别」`，取 7 种标准景别之一；`「画面」` 30~80 字；台词 ≤20 字（单格满版 ≤30 字）；
4. **每句台词都带说话人**（`说话人：“台词”`），从剧本原样搬运、不改写；剧本与原文冲突时以剧本为准；
5. 说话人不在画面内用 `「画外」`；角色内心活动用 `「心声」`；无人称叙述用 `「旁白」`，同一格只出现一个；
6. 关键动作/情绪转折可给独立页或独立格；重要道具/信息首次出现可给小格特写；
7. 保持人物空间关系连续（上一格在左，下一格不要跳到右）；
8. 全篇 20~30% 用非"上下双格"的格数组合（单格满版 / 3~4 格），避免通篇一个节奏；
9. **没有内容的字段整行不写**，不要留空字段、不要写"无"。

## 3. 剧本 → 分镜 的对应关系

| 剧本字段 | 落到分镜哪里 |
|---------|-------------|
| 地点 / 情绪 | 画面段的场景与神态（不明写，体现在描述里） |
| 剧情 | 页的数量与顺序（一句剧情 → 1~4 页） |
| 动作 | 画面段的动作主体，优先独立成页/格 |
| **对白** | `「台词」` 字段，**连同说话人一起原样搬运**（`说话人：“台词”`）；超 20 字拆成多格或多页，拆开后每句仍带说话人 |
| 本场目的 | 不进入分镜，用于筛页（对目的无贡献的页删掉） |
| 预估页数 | 页数锚点（±20%） |

**格数与剧情密度对照**：

| 剧情情况 | 建议格数 |
|---------|---------|
| 一句台词 / 一个动作 | 单格满版 |
| 对话来回（问 → 答） | 上下双格 / 左右双格 |
| 对峙、对比、双视角 | 左右双格 |
| 铺垫 → 发展 → 爆点 | 三格递进 |
| 情绪核心 + 细节补充（表情/手部/道具） | 不规则主从格 |
| 爆点、反转、结尾 | 单格满版（人物占比拉高） |

```

- 先把剧情切成"页"（一页承载一个完整节拍），再决定这一页内分几格。

- 一格 = 一个信息单元 = 一个镜头类型 + 一个情绪焦点 + 一个动作/反应；不要在一格里塞两个叙事节点。

【每一页怎么写】
- 页面标题：## 分镜 N · 单格 / 双格 / 三格 / 四格（N 从 1 递增，格数与页内实际格数一致）。

- 「动作」：这一格的肢体动作，10~25 字。
- 「表情」：这一格的神态与情绪，10~25 字。
- 台词类字段四选一，同一格最多出现一个：

【台词怎么写】（说话人不能省略，必须与剧本逐字一致）
- 对白：「台词」：说话人：“台词”

【其余字段】
- 「音效」：本格的声音，如 沙沙——衣料摩擦。没有就不写。

【原文核对】
- 原文分析仅作辅助核对：与剧本冲突时以剧本为准，不要机械按章节推断回忆、倒叙、变身等特殊状态。
```
