# 资产设定图版式 · 生图配置「版式」tab

> 配套改动（2026-10-06）：`asset-prompt` 模板瘦身为「只写主体自身的样子」，版式搬到
> **资产生图配置 → 「版式」tab**，按资产类型三段维护、生图前拼接。
> 文本本体在 `src/modules/comic/services/assetLayoutSpecs.ts` 的 `RECOMMENDED_LAYOUT_SPECS`。

## 位置与用法

资产 tab → **生图工作台** → 生图配置抽屉 → **「版式」tab**（第三个 tab）。

- 三个输入框：**人物 / 场景 / 道具**，各自一段版式文本。
- **留空 = 该类型不拼接版式**（输入框占位符有这句提示）。
- **首次打开抽屉（配置里从未有过版式）会自动预填推荐版式**，可见可改；已配置过则一律以你的值为准，清空后不会被悄悄填回来。
- 随「保存配置」一起落库；**改版式不必重跑提示词**，下次生图自动生效。

> ⚠️ 抽屉里**没有**「填入推荐版式 / 清空」按钮（2026-10-06 按用户要求移除，版式只能手改）。
> 若已清空并保存、想恢复推荐文本，从本文档下方「三段推荐文本」整段复制粘贴回输入框。

## 拼接位置

```
共用属性（插入最前） → 本类型版式 → 绘画提示词 → 共用属性（插入最后）
```

提示词正文保持纯净（可单独复制去外部 AI、可人工编辑），版式只在生图那一刻拼。

## 三段推荐文本

### 人物

```
统一角色设定版式：同一人物的四联角色设定图，横向 1×4 非等宽排布——第 1 格是 2:3 竖幅人像，宽度明显大于后三格；第 2~4 格等宽并排。影棚纯色中性灰（18% 灰）无缝背景，柔和伦勃朗光（45° 侧上方主光，面部受光侧形成柔和三角光斑），自然阴影与清晰皮肤细节。第 1 格：正面脸部大特写，2:3 竖幅，直视镜头、头不歪，裁切至锁骨，脸部占该格主要面积。第 2 格：全身正面，正对镜头，画幅从颈部中段以下开始。第 3 格：全身 3/4 前侧，身体转向约 45°，同样从颈部中段以下开始。第 4 格：全身背面，背对镜头，头部至脚部完整。整张图的脸只出现一次：第 1 格是唯一的高分辨率脸部，第 2、3 格头部完全在画幅之外——这是刻意的版式，把画幅让给服装，不是裁切失误，不要补画头部与五官；第 4 格背对镜头、看不到脸。四格一律 A-POSE，双手自然下垂、不持物、不插兜、不抱臂、不背包；四格同身高基准、统一头身比例，第 1 格的脸与第 2~4 格的身体属于同一个人。画面只有本角色与四个画格，不出现第二个人物或动物，无文字、无标注。
```

### 场景

```
统一空间全景版式（establishing shot）：广角平视，只交代空间结构与标志物位置的空间全貌图，不做情绪渲染、不做局部特写、不加风格化处理；画面只有该空间本身，不出现人物与动物，除空间固有招牌外无文字与水印。单张单格，不要自行加多视角或多机位。
```

### 道具

```
统一道具设定版式：中性 18% 灰哑光背景，同一件道具的正面、侧面、顶视三个视图等距并排、同比例同大小，另附一处关键细节放大特写；各视图下方或角落标阿拉伯数字 1–4；道具完整入画、不裁切不遮挡，画面中只有该道具，不出现人物、不出现手持动作、不出现场景与台面，除视图标号外不出现任何文字与水印。单张单格拼版，不要自行加其他视角。
```

## 三条口径（别踩）

- **机位图是唯一例外**：状态名含「机位图」时，场景版式**自动跳过**（`resolveLayoutPrompt` 里判的），因为那一条的 3×3 九宫格版式由 `asset-prompt` 模板写在提示词正文里。两种版式同时拼会互相打架。
- **图号不受影响**：版式是纯文字，不挂参考图、不参与 `getSharedRefImages`。这也是它优于「按类型过滤共用属性块」的关键 —— 那种做法会让同一块的图号在不同类型下不同，文字里的「图N」与实际发送的图就会错位。
- **分镜侧没有这个字段**：`layoutPrompts` 只存在于 `AssetGenConfig`，`composeFinalPrompt` 不读它；分镜绘图配置抽屉也不显示「版式」tab。

## 改版式要一起查的地方

推荐文本与模板是**配合关系**，改任一边都要看另一边：

| 改动 | 要一起看 |
|---|---|
| 改推荐版式文本 | `assetLayoutSpecs.ts` 的 `RECOMMENDED_LAYOUT_SPECS` + `tests/features/assetLayoutSpecs.test.ts`（人物「脸只出现一次」那组断言） |
| 改「模板不写版式」的分工声明 | `promptTemplateRegistry.ts` **三处同改**：【与共用属性、版式的分工】／`ASSET_PROMPT_FORMAT` 格式段／`description` + 测试断言 |
| 改机位图判定 | `services/sceneRefSheetNeeds.ts` 的 `REF_SHEET_VARIANT_NAME`（两处共用同一常量，不要新写字符串） |
