# 长篇故事「剧本 / 分镜」设计方案

> 目标：把「分镜」从视频分镜语言修正为**漫画页**语言，重新设计剧本→分镜的生成格式、
> 结构操作（合并/拆分/新增/删除/移动）与分镜页（与生图同页）的呈现和按钮摆放。
> **修订**：第 2/3/4/5 节已同步到 v3「页块格式」与「台词必须带说话人」；
> 第五节最终定稿为「**页签行「分镜」下拉切换 + 右栏原样两按钮 + 单一输入框 + 顶栏只放当前阶段动作**」，并已落地（进度与改动清单见第 8 节）。

分镜 tab 布局：顶栏按钮（批量推导描述 / 批量生图 / 导出发布 / 资产 / 绘图配置）+ 左列表（缩略图+状态，右键结构操作）+ 中预览（成图+资产绑定）+ 右栏 `[分镜内容|提示词]` 双 tab。

## 二、核心概念：分镜 = 一页漫画（三层内容模型）

### 2.1 视频分镜 vs 漫画分镜（页）

| 维度 | 视频分镜（现状误用） | 漫画分镜 = 页（本方案） |
|------|--------------------|-----------------------|
| 基本单位 | 镜头（一场拆 3~8 个） | **一张漫画图 = 一个分镜；图内可单格，也可 1~4 格** |
| 关心什么 | 景别、机位、正反打、时长 | 这一拍讲什么、图内分几格、每格什么镜头、台词放多少 |
| 与产物关系 | 镜头 ≠ 最终画面产物 | 页序直接对应成图顺序与导出文件名 |
| 台词 | 台词属于镜头，多镜共享、不署说话人 | 台词排上页面（气泡/旁白框），**必须带说话人**；每格 ≤ 20 字、单格满版 ≤ 30 字，超了拆格/拆页 |
| 景别/视角 | 必填字段（镜头） | 仍必填（7 选 1），但它是**推导锚点**，具体占比/景深由画面描述环节按规则库落 |

### 2.2 三层链路与职责

```
剧本（场景层）              分镜（页块层）                画面描述（绘画层）        成图
## 场景 N                一页一块，一格一行              一格 / 一页一段描述       一页一图·竖屏
一场一组信息浓缩           ①【镜头】画面 + 说话人：台词     分格结构/人物占比/浅景深
```

- **剧本**：回答"这一章讲什么"，按场景组织，是分镜生成的上下文底稿；
- **分镜（页块层）**：回答"这一页里分几格、每格什么镜头、画什么、谁说什么"，是最贴近产物的结构层；
- **画面描述**：回答"这一格具体怎么画"，承接规则库（6 种分格结构、人物占比铁律、浅景深、R13/R14 视角一致性、气泡规范），输出自包含生图提示词。

> 结论：**JSON 等强结构放在画面描述层**（与"每页自包含 JSON 绘画提示词"的既定方向一致），
> 分镜层保持轻量页块格式，好生成、好手改、好合并拆分。

## 三、生成格式设计

### 3.1 剧本格式（场景层，基本保留 + 微调）

保持 `## 场景 N` + `- 属性名：内容` 结构，调整三点：

1. **对白写最终台词并带说话人**：`说话人：台词`，分镜只搬运不改写（含说话人一起搬）；
2. **每场景加"预估页数"字段**：给分镜生成节奏锚点（如 `- 预估页数：4`），一章建议 10~25 页；
3. **支持"节拍式剧本"**：scriptOnly 起笔模式允许直接一行一拍写故事（竞品式），分镜模板对节拍式输入做"按页拆分+补画面+推定说话人"处理。

### 3.2 分镜格式（页块层）——方案对比

| 方案 | 形态示例 | 优点 | 缺点 | 结论 |
|------|---------|------|------|------|
| A. 现状字段行 | `## 分镜 1`<br>`- 画面：…`<br>`- 镜头：近景`<br>`- 对白：…` | 字段全 | 输出冗长、靠续行拼接；多格无法表达 | 弃（仅保留解析兼容） |
| B. 纯节拍行（竞品） | `角色B，你怎么能那么残忍？破坏了它的关键部分…` | 极简、生成快 | 画面/台词混在一起；表达不了分格；**丢了说话人** | 备选（解析器兼容） |
| C. 单行分格（v2） | `近景｜角色A指节收紧 ‖ 中景｜角色B皱眉｜破坏关键部分跟要了命有什么区别？` | 紧凑 | **整页挤在一行**：多格时人读不动、模型易漏 `‖` | 弃（改为 C′） |
| **C′. 页块格式（推荐）** | `## 分镜 2 · 双格`<br>`①【近景】角色A指节收紧，关键道具缠上小臂。`<br>`角色A：破坏了它的关键部分，跟要了它的命有什么区别？`<br>`②【中景】角色B站在沙发边，眉头拧起。` | 一页一块、一格一行；**台词带说话人**；多格可读、好改、好查；解析极简 | 输出 token 略增 | **✅ 采用** |
| D. 页 JSON | `{"page":1,"scene":"…","dialogue":"…"}` | 结构最强 | 输出冗长易截断、手改困难 | 留给画面描述层 |

**定性**：从「一行一图」改为「**一页一块、一格一行**」。它是 v2 的升级而非推翻——核心理念（分镜 = 一页 = 一张图，图内 1~4 格）不变，只是把"挤在一行"改成"格逐行"。

### 3.3 推荐格式规范（方案 C′，全文见「格式定稿」文档）

**一页一块；一格一行；台词独立成行并带说话人。**

```
## 分镜 2 · 双格
①【近景】角色A指节收紧，关键道具缠上小臂。
角色A：破坏了它的关键部分，跟要了它的命有什么区别？
②【中景】角色B站在沙发边，眉头拧起。
```

| 元素 | 写法 | 对应数据模型 |
|------|------|-------------|
| 页头 | `## 分镜 N · X格`（X = 单格/双格/三格/四格）；解析按出现顺序，序号仅为阅读 | 一个 `LongProjectStoryboardPanel` |
| 镜头 | 格行 `①【镜头】画面` 的 `【】` 内；7 选 1（必填），人物占比/景深/焦段的推导锚点 | 格级 `shot` |
| 画面 | `【】` 后；谁 + 在做什么 + 神态/情绪，15~40 字 | 格级 `content` |
| 台词 | 独立行 `说话人：【台词】`（正文带【】、说话人在外）；≤20 字（单格满版页 ≤30 字） | 格级 `dialogue` + `speaker` |
| 心声 / 画外 | `说话人（心声）：【…】` / `说话人（画外）：【…】` | 格级 `dialogue` + `speaker` + `delivery` |
| 旁白 | `旁白：【文字】`（无人称） | 格级 `narration` |
| 格 | 页内 1~4 格，`①`~`④` 随格序 | 新增 `panels[]` 子结构 |

**为什么要写说话人**：说话人决定气泡挂在谁头上、谁要张嘴给表情、绑定哪个角色资产。剧本里已经写了说话人，分镜必须**原样搬运**，不能再丢。

节奏规则（写入模板）：
- 每格台词 ≤ 20 字，单格满版页 ≤ 30 字，超了拆格或拆页；
- 一格 = 一个信息单元（一个镜头 + 一个情绪焦点 + 一个动作/反应），不塞两个叙事节点；
- 一格只放一个角色的台词，双人对话拆两格；
- 全篇 20~30% 用单格满版或 3~4 格，避免通篇上下双格；
- 大段内心独白拆成多张心声/旁白页。

> 数据模型影响：现有 `LongProjectStoryboardPanel` 是"一分镜 = 一图 = 单段内容"，
> 支持页内多格需引入"图 → 格"两级结构（`panels[]`），详见「格式定稿」v3 第 2 节。

### 3.4 输出协议（storyboard 默认协议改写）

```
只输出中文 Markdown，不要解释、代码块或 JSON。
每一页写成一个 ## 分镜 N · 单格 / 双格 / 三格 / 四格 小节（N 从 1 递增）。
一页内每一格单独一行，以 ① ② ③ ④ 开头，紧跟【镜头】，再写画面。
台词另起一行写在所属格下面，格式「说话人：【台词】」（正文带【】、说话人在外）；说话人不能省略，必须与剧本一致。
内心独白写「说话人（心声）：【…】」；说话人不在该格画面内写「说话人（画外）：【…】」；
无人称旁白写「旁白：【…】」；没有台词就不写台词行。
镜头取 远景 / 中景 / 近景 / 特写 / POV / 过肩 / 仰拍 之一；画面 15~40 字。
每格台词不超过 20 字；单格满版页不超过 30 字。
按剧本对白直接搬运，不改写；剧本冲突时以剧本为准。
```

### 3.5 解析与兼容策略

- `parseStoryboardResponse` 改为**逐行状态机 + 多格式兼容**：
  1) **新页块格式**：`## 分镜 N · X格` 起页 → `①【镜头】画面` 起格 → `说话人：【台词】` / `旁白：【文字】` 归属最近的格；
  2) **v2 单行分格**：按 `‖` 分格、`｜` 分三段（旧 run 数据继续可读）；
  3) **竞品纯节拍行**：整行入该页首格画面，无说话人；
  4) **旧 `## 分镜 N` + `- 字段：` 格式**：保留原逻辑兜底。
- 说话人识别：行首 `X：` 中 X 为说话人（支持 `X（心声）` / `X（画外）`），保留字 `旁白` 走 narration；
  说话人再与资产库角色名做绑定回填。
- **数据模型需扩展**：由"一分镜 = 单段内容"升级为"图 → 格"两级（新增 `panels[]`，格含 shot / content / speaker / dialogue / delivery / narration）；
  旧 run 数据按"整行 = 单格图"自动兼容，无需手工迁移；
- 自定义了 storyboard 模板输出协议的老项目不受影响（自定义协议优先级高于默认协议）。

## 四、分镜结构操作设计（合并 / 拆分 / 新增 / 删除 / 移动）

### 4.1 操作清单

| 操作 | 现状 | 设计 | 说明 |
|------|------|------|------|
| 新增空白图（上/下） | ✗（只能靠"向上/向下拆分"变通） | ✅ 列表底部「＋ 新增图」+ ⋯ 菜单 + 右键 | 新图空 1 格，选中后直接在右栏写镜头/画面/台词 |
| 删除图 | ✗ | ✅ ⋯ 菜单 + 右键 + Delete 键 | 有成图的图二次确认；复用 8 秒撤销条 |
| 上移 / 下移 | ✗ | ✅ ⋯ 菜单 + 右键（拖拽排序放二期） | 与相邻图交换 order 后重排 |
| **合并图** | ✓ 仅右键、≤3 | 保留，入口加 ⋯ | **语义升级：两张图合成一张图（格拼接）**，一图最多 4 格，超出提示 |
| **拆分图** | ✓ 空行拆段 | 交互改为「格拆分」 | 见 4.2 |
| **格增删 / 格排序** | ✗ | ✅ 右栏页编辑器内 | 页内加一格、删一格、上下调格序（页内操作，不改页序） |
| 复制内容 | ✓ | 保留 | 复制为该页页块文本（`## 分镜 N · X格` + 格行 + 台词行） |
| AI 续图 | ✗ | ✅ 二期可选 | 从选中图之后，基于剧本上下文续写 N 张图草稿（插入而非覆盖） |
| 多选批量操作 | ✗ | 三期 | 批量删除 / 批量重新推导 |

### 4.2 拆分交互改造（页块格式下的新语义）

现状拆分弹窗按"空行拆段"，新格式下一页含多格、一格一行，拆分语义变为**格拆分**：

- `multi`：一张 3 格图拆成"1 格图 + 2 格图"（在格列表里选切分点）；
- `up` / `down`：把页内某一格拆出来，成为当前页上方/下方的一张新页；
- 弹窗展示当前页全部格（镜头 / 画面 / 台词 三字段可编辑，台词含说话人），实时预览拆成的每一页；
- 约束沿用现状：第一页（或父页保留段）继承父页 ID 保留成图，内容变化的页标记"描述过期"。

### 4.3 入口与可发现性

- **右键菜单保留**（快捷用户）；
- **列表项 hover 显示 ⋯ 按钮**（下拉菜单与右键同源）——解决右键不可发现问题；
- **列表底部常驻「＋ 新增页」**；
- 键盘：↑/↓ 切换页，Delete 删除当前页；
- 批量任务进行中锁定结构操作（沿用现有 `opsLocked`）。

## 五、页面呈现与按钮摆放（分镜 tab，与生图同页）

> **修订（最终）**：此前三版（「右栏每格一卡编辑器」/「顶栏 `[分镜│绘图]` 切换段」/「右栏标题栏下拉」）**均已作废**。
> 最终定稿：**页签行左侧的「分镜」页签本身做成下拉按钮**（默认分镜，可下拉切到绘图）；
> 右栏标题栏**保持改动前的原样**（左侧说明文字 + 右侧 `分镜内容 | 提示词` 两个按钮），两者共用同一个 `stage` 状态。
> 顶栏只放「当前阶段的动作组」，随阶段变化；`资产` 常驻，`绘图配置` 归属绘图（提示词）阶段。
> 核心一句话：**一个状态、两个入口（页签行下拉 / 右栏按钮），同时决定顶栏按钮组、右栏输入框内容、右栏底部操作。**

### 5.1 现状的三个割裂点

| # | 位置 | 当前内容 | 层级 | 问题 |
|---|------|---------|------|------|
| 1 | 顶栏 `#storyboard-actions` | 批量推导描述 / 批量生图 / 导出发布 ‖ 资产 / 绘图配置 | 章节级 | 一排 5~6 个按钮，无语义分组 |
| 2 | 右栏 header | `分镜内容 \| 提示词` 切换 | 视图切换 | 位于输入框**上方** |
| 3 | 右栏底部（分镜内容） | 「生成分镜 / 重新生成分镜」+ 手动导入 | **章节级** | 放在**当前分镜**的编辑框下方，被读成"生成这一个分镜"，实际是生成整章全部分镜 → **层级错位** |
| 3′ | 右栏底部（提示词） | 「单镜操作：AI 推导 / 单独生成」 | 单镜级 | 正确 |

**根本矛盾**：同一个章节级动作（生成分镜）被拆到两处——顶栏（批量推导/批量生图）与右栏底部；
而右栏的切换（输入框上方）与操作（输入框下方）被输入框隔断，**切换不驱动操作**，操作逻辑不自洽。

### 5.2 解法：把「视图切换」升级为「内容阶段切换」，一个状态驱动三处

页面级状态 `stage: 'storyboard' | 'draw'`（取代原右栏局部 `rightTab`），由主页面 `LongProject.vue` 持有，
经 `v-model:stage` 注入分镜 tab。切换 = 同时切换：

1. 顶栏显示哪组**章节级动作**；
2. 右栏输入框显示**哪种文本**（分镜页块 / 画面描述提示词）；
3. 右栏底部显示哪组**页级 / 单镜操作**。

```
┌───────────────────────────────────────────────────────────────────────────┐
│ 原文 剧本 [分镜⌄] 资产│[⚙ 模型 · 模板 ⌄][生成分镜][手动导入]‖[资产]│ ← ① 页签下拉 + 当前阶段动作
├──────────┬────────────────────┬───────────────────────────────────────────┤
│ P01 成图  │ 成图预览            │ 分镜内容（剧本 → 分镜）  12 页 [分镜内容|提示词]│ ← ⑤ 右栏恢复原样
│ P02 已描述│ + 资产绑定          │ ┌───────────────────────────────────────┐ │
│ P03 未推导│ （不变）            │ │ ①【近景】角色A指节收紧，关键道具缠上小臂。  │ │
│ ＋新增页  │                    │ │ 角色A：破坏了它的关键部分，跟要了它的命…       │ │
│          │                    │ │ ②【中景】角色B站在沙发边，眉头拧起。   │ │
│          │                    │ └───────────────────────────────────────┘ │
│          │                    │ 本页操作：[AI 优化]                          │ ← ⑥
└──────────┴────────────────────┴───────────────────────────────────────────┘
```

> **修订（右栏底部，最终）**：右栏底部不再放结构操作（新增页 / 上移 / 下移 / 合并 / 拆分 / 删除）——
> **结构操作全部收进左栏分镜列表的右键菜单**（唯一入口）；
> 右栏底部改为**与「提示词」模式「单镜操作」同款卡片**，只放**与当前这一页内容相关**的操作：
> `AI 优化`（按分镜协议规整本页）。`AI 推导` 与 `复制` 已移除——两者在「提示词」阶段的
> 「单镜操作」与右键菜单「复制分镜内容」里各有归属，避免同一能力在三处重复。

### 5.3 页签行（①）：「分镜」页签做成按钮 + 下拉

```
原文  剧本  [ ▤ 分镜 ⌄ ]        ← 左半 = 进入分镜创作台；右半 = 下拉切 分镜 / 绘图
                 ├ 分镜    剧本 → 分镜 · 逐页编辑      ← 当前
                 └ 绘图    分镜 → 画面描述 · 生成画面
```

- **左半按钮**：进入分镜创作台（保留页签高亮态），一次点击即达，与「原文 / 剧本」页签的点击行为一致 ——
  避免"进分镜页还要先点一次下拉"；**默认即分镜**；
- **右半下拉**：点开两项菜单（`分镜` / `绘图`），选中即切到分镜页签并写入 stage；
  按钮文案随当前阶段变为 `分镜` 或 `绘图`（图标同步 `Clapperboard` / `Palette`，chevron 展开时旋转 180°）；
- 点击空白处自动关闭（主页面根节点统一收浮层）；
- **为什么放在这**：这是主页面唯一的"分镜入口"，阶段切换挂在这里，用户不必先进入分镜页再找切换控件；
  顶栏因此**不必再放任何切换段**。

### 5.4 顶栏（①）：只放当前阶段的动作组

```
分镜阶段： [⚙ 模型 · 模板 ⌄] [生成分镜] [手动导入]  ‖ [资产]
绘图阶段： [批量推导描述 N] [绘图配置] [批量生图 (N)] [导出发布]  ‖ [资产]
```

| 阶段（页签文案） | 章节级动作 | 说明 |
|------|-----------|------|
| **分镜**（右栏叫「分镜内容」） | `生成分镜 / 重新生成分镜`（PromptRunBar：**紧凑形态**——`⚙ 模型 · 模板` 单按钮下拉，弹层内改 模型 / 模板 / 发送前确认 + 执行）+ `手动导入` | 顶栏横向空间紧张，模型与模板不再平铺成两个 select；弹层与「原文 / 剧本」页签同款 PromptRunBar 一致 |
| **绘图**（右栏叫「提示词」） | `批量推导描述` + `绘图配置` + `批量生图 (N)` + `导出发布` | 生图阶段核心动作，批量生图保持主按钮样式；**`绘图配置` 紧贴 `批量生图` 左侧**（调参 → 生图的自然动线） |

- **PromptRunBar 的两种形态**：宽形态（可用宽度 ≥600px，平铺 `模型▾ / 模板▾ / □发送前确认`）与
  紧凑形态（`⚙ 摘要 ⌄` 单按钮 + Teleport 弹层）。分镜页签通过 `force-compact` **锁定为紧凑形态**，
  不再占用两个 select 的横向空间；`原文 / 剧本 / 资产` 页签仍保持宽形态。
- **`绘图配置` 从"常驻工具"移入绘图阶段** —— 它设置的是绘画模型与共用属性，只在生图链路里才有意义；
- **`资产` 保持常驻**（章节级抽屉入口，两个阶段都会用到），右对齐、竖线分隔；
- 空态（本章无分镜）：分镜阶段仍显示「生成分镜」；绘图阶段三个按钮禁用；
- 同屏按钮 ≤ 4 个。

### 5.5 右栏（⑤）：标题栏恢复原样 + 保持**单一输入框**

- **标题栏**（回到改动前的形态）：左侧一行说明文字（`分镜内容（剧本 → 分镜）` / `绘画提示词（分镜 → 画面描述）`），
  中间为本阶段状态（`N 页` / `N/M 已描述` / `分镜生成中…`）——**不再显示「上次生成失败」常驻红字**：
  run 的历史失败记录照旧落库（`status: 'failed'` + `error`，便于排查），但界面只在失败当下用 toast 告知；
  避免"已有可用分镜，却因为之后一次生成尝试失败而长期挂着红字"的误导，
  右侧为 `分镜内容 | 提示词` 两个切换按钮；
- **这两个按钮与页签行下拉共用同一个 `stage`**（`defineModel` 双向绑定）：点任一处，另一处立即同步，永不打架；
- **输入框**（结构不变：一个圆角卡片 + 一个 textarea）：
  - 分镜内容：当前页的**页块文本**（`①【镜头】画面` + `说话人：【台词】` 行）——与生成格式、与可复制格式**完全一致**，所见即所得，直接改；
  - 提示词：当前页的画面描述（现有资产高亮不动）。
- **底部操作**（⑥，随阶段变化，**同款卡片**）：
  - **分镜内容 —— 本页操作**（与提示词阶段「单镜操作」同款卡片：标题 + 左信息 + 右按钮）：
    | 按钮 | 作用 | 说明 |
    |------|------|------|
    | `AI 优化` | 把本页页块文本按分镜输出协议规整：补/改【镜头】、拆超长台词、补说话人写法、画面补足 15~40 字 | 用顶栏所选分镜模型；**不改动剧情与台词文字**；结果解析回格列表回写 |
    左信息：`分镜 N · X 格 · 修改自动保存`。
    > 只保留 `AI 优化`：`AI 推导` 归属「提示词」阶段的「单镜操作」，`复制` 归属右键菜单「复制分镜内容」，
    > 同一能力不在三处重复。结构操作（新增页 / 上移 / 下移 / 合并 / 拆分 / 删除）**也不在此处**，见 5.6 左栏右键菜单。
  - **提示词 —— 单镜操作**：保留 `AI 推导 / 单独生成`（不变）。

### 5.6 左栏列表（③④）：结构操作的**唯一入口**（右键菜单）

左栏列表项 `@contextmenu` 打开 `StoryboardContextMenu`，分三组：

```
│ 上移一页 / 下移一页
│ 在上方新增页 / 在下方新增页
├───────────────
│ 向上合并 [1] 个 / 向下合并 [1] 个   （行内数字框，默认 1，可编辑，≤3）
│ 拆分此分镜… / 向上拆分… / 向下拆分…
├───────────────
│ 复制分镜内容
├───────────────
│ 删除这一页（红色；仅剩一页时禁用）
```

- **无菜单头**：不显示 `分镜 N · 镜头` 摘要，菜单直接从操作项开始（更紧凑，视线不被"标题"打断）；
- **合并去掉二级子菜单**：原先 `向上合并 ▸` 悬停出"与上 N 个"列表，改为**行内数字输入框**——
  文案 `向上合并 [1] 个`，中间数字默认 `1`、可直接键入，点整行或按回车即执行；
  数值按可用相邻页数自动收敛（上方只有 2 页时输入 9 也只会合并 2 页），上下方向各自独立记忆输入值；
- **移除「在生图工作台查看」**：该入口原为跳转旧独立工作台，生图工作台已并入本页，能力重复；
- **贴底自动翻转**：菜单以光标为锚点展开，**下方空间不足且上方更充裕时改为向上展开**（菜单底边贴住光标），
  避免在列表底部右键时菜单被视口底边裁掉；左右边界同样自动收进视口内；
- 由此**取代**原先只有「合并 / 拆分 / 复制」的菜单，也取代右栏底部那排结构按钮 —— 页面里**只有这一处**能改结构，
  避免"按钮一排 + 右键一份"两套并存、能力不一致；
- 操作后**自动跟随选中**：上移 / 下移跟随到新位置，新增页直接选中新页，可就地输入；
- 所有操作沿用 8 秒撤销条（新增 / 删除 / 移动 / 合并 / 拆分均可撤回）；
- 列表项本身：标题 **`P01`**（替换"第 N 话"）+ 一行文字预览（优先本页首句台词含说话人，无台词取画面）；
- 顶部一行流水线状态条：`分镜 12 页 → 描述 8/12 → 成图 3/12 → 导出`（点阶段可筛列表，首版可只展示）。

### 5.7 方案对比（为什么选「页签下拉 + 右栏按钮」双入口）

| 方案 | 形态 | 优点 | 缺点 | 结论 |
|------|------|------|------|------|
| **A. 页签行「分镜」下拉 + 右栏按钮（最终采用）** | 分镜页签 = 按钮 + 下拉（分镜 / 绘图）；右栏 header 保留 `分镜内容 \| 提示词` 两按钮；顶栏只放当前阶段动作 | 一个状态两个入口，两处永远同步；分镜入口处即可切换；右栏保留老用户熟悉的两按钮；顶栏零占用 | 同一状态两处控件（但状态共享，不存在不一致） | **✅ 采用** |
| B. 顶栏 `[分镜│绘图]` 切换段 | 切换在顶栏最左 | 一次切换驱动三处 | 占用顶栏宽度；切换离它影响的内容远 | 弃（已改） |
| C. 右栏标题栏下拉 | 右栏 header 一个下拉 | 切换与内容紧邻；不占顶栏 | 需先进入分镜页才能切；丢掉老用户熟悉的两个按钮 | 弃（已改） |
| D. 不切换，只加分隔线分组 | 顶栏 6 个按钮分三组 | 无额外点击 | 按钮仍然多，未解决"太多" | 弃 |
| E. 右栏下方加二级 tab 行 | 主 tab 下再一行子 tab | 像传统 tab | 双层 tab 阶梯，多占一行高度 | 弃 |
| F. 结构操作放右栏底部按钮条（上一版） | 输入框下方 `＋新增页 ↑ ↓ ⋯拆分 删除` | 显性、一眼可见 | 与「提示词」阶段底部风格不一致；和右键菜单能力重复、两套并存；底部还有 AI 动作时按钮挤一排 | 弃（已改） |
| **G. 结构操作只放左栏右键菜单（最终）** | 右键菜单分四组：页序 / 合并 / 拆分 / 复制·删除 | 页面里只有一处能改结构，能力与入口一一对应；右栏底部腾出来给"这一页的内容操作"；与「提示词」阶段底部样式统一 | 右键入口需要一点学习成本（用"贴底自动翻转 + 行内合并页数"降低操作成本，不用菜单头占位） | **✅ 采用** |
| H. 右栏底部保留 `AI 优化 / AI 推导 / 复制` 三按钮（上一版） | 三按钮并排 | 一次可达 | 与「提示词」阶段「单镜操作」重复（AI 推导）、与右键菜单重复（复制）；同一能力三处入口 | 弃（已改） |

### 5.8 风格

极简、小圆角 4px、无多余装饰；下拉菜单沿用现有控件样式（`bg-elevated` + 0.5px 边框 + `shadow-black/40`）；
