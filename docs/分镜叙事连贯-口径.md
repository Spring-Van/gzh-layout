# 分镜「叙事连贯」口径（全章台词 + 旁白要能连读成一条故事线）

> 配套改动（2026-10-07，用户实报要求）：
> **「所有分镜要把整个事件串联起来，主要通过旁白内容和对话内容，这两个要能知道整个小说的走向和故事」**。
> 模板正文：`src/modules/comic/services/promptTemplateRegistry.ts` 的 `storyboard`。

## 一句话口径

**把全章每一格的「台词／心声／画外／旁白」抽出来、按格序连读一遍，读者不看画面也要能看懂整条故事线。**
断了的地方，用**一条衔接旁白**把跨度过桥——只在断层处补，不是每页都写。

## 缺的是什么：不是分辨率，是「过桥」

现有 `【旁白怎么写】` 的旧口径是「来源唯一＝逐字继承剧本／原文，没有叙述文字就整行省略、不要自己编」。
看起来严谨，但漏了一类情况：

> **剧本与原文都没写叙述句，而这一页已经跨了时间／地点／视角** → 这一页一个字都没有 → 读者断线。

这正是 McCloud 六种镜头衔接里最危险的一种：**scene-to-scene**。

| 衔接类型 | 读者要做的推理 | 需不需要文字过桥 |
|---|---|---|
| moment-to-moment（睁眼 → 闭眼） | 几乎不用 | 不需要 |
| action-to-action（挥拳 → 拳头命中） | 因果 | 不需要 |
| subject-to-subject（同场景换焦点） | 少量 | 一般不需要 |
| **scene-to-scene（跨时间／跨空间）** | **大** | **必须**：配一条 caption（旁白）或一个定场画面 |
| aspect-to-aspect（同瞬多细节） | 情绪 | 不需要 |
| non-sequitur | 无逻辑 | 不用于叙事漫画 |

McCloud 的原话：**「Always pair with a caption or an establishing shot or the reader is lost.」**
另一本分镜模板的 FAQ 点出最常被漏的两件事：**「这一格是谁的视角」和「距上一格过了多久」**——
「Leave those out and the finished art will feel off.」

## 三层各自管什么（不要重复造）

| 位置 | 剧本（章级） | 分镜（页级） | 画面描述（格级） |
|---|---|---|---|
| 开场／章末钩子 | **管**（§20：爆点前置、六类钩子） | 不管 | **章末页强化**（既有） |
| 跨时间／跨地点／跨视角 | 提供「场景头：地点 + 时间」 | **管**：跨场第一页补衔接旁白 | 不变（照抄文字转写气泡/方角框） |
| 剧情点是否可懂 | 提供剧情与台词 | **管**：主线落在台词或旁白上 | 不变 |

⚠️ **衔接旁白只放在分镜层，不动剧本层**：剧本每个场景头已写明「地点 + 时间」，
分镜跨场时**信息全在剧本里**——从剧本取材不算编造，不必在 `script` 再加一套转场规则（两层重复会口径打架）。

## 三类断层 + 写法

**必须**用一条**旁白**（无人称叙述）把跨越交代清楚，落在跨越发生的那一页、**优先本页没有台词类文字的那一格**：

| 断层 | 什么时候算 | 可画的写法 |
|---|---|---|
| **时间跨越** | 过了一夜／几天／几年 | 「三日后」「次年春天」 |
| **地点转移** | 从一处换到另一处 | 「与此同时，城东的旧宅」 |
| **视角切换** | 叙事线从一个人换到另一条线 | 「另一边，林小雨还不知情」 |

**取材边界（红线）**：只允许来自**剧本的场景头（地点、时间）与前后场景的关系**——
**只交代跨度，不写剧情**；不得借它新增事件、新增人物或改写对白。

## 与「原文旁白」的区别

| | 原文旁白（主来源） | 衔接旁白（跨度的桥） |
|---|---|---|
| 何时用 | 剧本／原文本来就有叙述句 | 剧本／原文都没有、但本页跨了时间／地点／视角 |
| 取材 | 剧本「旁白」行／原文叙述句，**逐字** | 剧本场景头（地点、时间）+ 前后场关系 |
| 能不能改字 | 不能（不改写、不概括、不合并） | 是本次新写的，但只写跨度、不写剧情 |
| 占不占额度 | 占（每格 ≤20 字、每页合计 ≤60 字） | 占，且要短——一句话说完跨越 |

## 另外三条

1. **因果断口用台词或旁白补前因**：某一格人物做的事靠画面看不出来为什么时，带出一句前因或动机——只能用剧本与原文已有的信息。
2. **主线必须落在文字上**：画面由模型生成、不保证把剧情画准；关键选择／关键揭示／关系变化一律由台词或旁白明说，不靠画面暗示。
3. **不许复述**：衔接旁白只交代跨越本身，不重复画面已经能看清的事、不重复台词已经说过的内容
   （「一个孤独的身影走在空荡的街上」配图正是这个画面＝噪音，这是漫画脚本最常见的错误之一）。

## 样例（同一段分镜，改前 / 改后）

设定：本章有两条线，林知夏（主）与哥哥（副）。剧本场景 3 头是「老巷口 深夜」，
剧本场景 4 头是「学校走廊 三日后 上午」。

**改前（旧模板，跨场无过桥）**：

```
## 分镜 7 · 上下错位双格

第1格
景别：远景
镜头：平视
画面：老巷口空镜，雨后地面反光，路灯下没有人。
（……）

## 分镜 8 · 不规则主从格

第1格
景别：近景
镜头：平视
画面：林知夏站在学校走廊里，同学从她身边经过，她低头看着手里的一叠旧试卷。
旁白：她终于看清了最上面那张的名字。
```

> 问题：从「深夜巷口」跳到「白天学校走廊」，**没有任何文字交代过了多久、为什么到了这里**。
> 读者只能靠画面猜——而画面是模型生成的，不保证画得出季节、时段与场景差异。文字连读断了。

**改后（新模板，跨场补衔接旁白）**：

```
## 分镜 7 · 上下错位双格

第1格
景别：远景
镜头：平视
画面：老巷口空镜，雨后地面反光，路灯下没有人。
（……）

## 分镜 8 · 不规则主从格

第1格
景别：近景
镜头：平视
画面：林知夏站在学校走廊里，同学从她身边经过，她低头看着手里的一叠旧试卷。
旁白：三日后，学校走廊。

第2格
（……）
旁白：她终于看清了最上面那张的名字。
```

> 改后做了什么：**只加了一条衔接旁白**（「三日后，学校走廊」），信息全部来自剧本场景头
> （时间＝三日后、地点＝学校走廊），没有新增任何事件。
> 现在把全章文字连起来读：「……三日后，学校走廊。她终于看清了最上面那张的名字。」
> 读者不看画面也能接上时间与地点。

## 三条防呆（每条对应一个已踩过的坑）

| 约束 | 不写会怎样 |
|---|---|
| **只在断层处补，不是每页都写** | 「每一页都要交代跨度」＝**又一个固定尾段**（本项目刚因 §19 媒介质感锚踩过：「每条都要带 X」＋封闭取值域必退化） |
| **自检不要写进任何一格的输出** | 读一遍校验是判断标准；不写这句，模型会把它当成每格必答内容 |
| **衔接旁白只交代跨度、不写剧情** | 放开「可自己写旁白」而不设边界 → 模型借旁白编造事件、改写原著（与剧本层「旁白逐字保留」冲突） |

## 生效三步

1. **设置页 → 提示词模板 →「长篇章节分镜」→「填入推荐模板」**（存量模板优先，不点不生效 —— 这是「改了没效果」的第一排查项）。
2. 存量分镜需要**重新生成**才会带上叙事连贯与衔接旁白。
3. 按现有习惯，分镜重新生成后页面描述需要重新推导（工件迁移会丢弃正文已变的描述，成图跟随保留）。
