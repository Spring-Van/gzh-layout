# 资产绘画提示词（asset-prompt）· 新口径与示例

> 配套改动（2026-10-07）：模板从「**转译器**」改成「**设定稿撰写者**」——
> 清单给事实骨架，笼统或缺失的维度**由模型补全到可画精度**。
> 同日的第二次口径修正：人物字段「**性格**」→「**气质**」，并照 `character-casting-studio`
> 的设计方法论补上「面部张力」与「人物差异矩阵」（见文末《外部方法论迁移》）。
> 模板正文：`src/modules/comic/services/promptTemplateRegistry.ts` 的 `asset-prompt`。

## 一句话口径

**清单优先，脑补补全。** 清单写到的原样保留、零冲突；清单没写到或写得笼统的维度补全到能画出来，不留「某色」「某种材质」这类空档。

## 三条硬边界

| 边界 | 内容 |
|---|---|
| **清单怎么读** | 优先级：**固定特征**（逐字必写）> **资产描述**（身份基准）> **属性字段**（身份/职业/时代/地域，人物的**气质**也在这里，照守）> **视觉描述**（本状态差异点） |
| **补全三档** | **必须补**：不补就画不出来的（颜色/材质/款式/尺寸/磨损）｜**克制补**：决定「这是谁」的强身份特征，取最合理、最不抢戏的取值｜**禁止补**：与清单冲突、改时代地域身份、新增清单外实体、情绪动作台词镜头 |
| **跨状态一致** | 同一资产的所有状态**共用同一套身份取值**（性别/年龄/身高体型/脸型/发型/肤色/气质基调/识别锚点），只在该状态声明变化处改。零矛盾优先于「写得更丰富」 |

## 补全的取舍顺序（两套补全方案打架时）

```
清单硬事实  >  气质  >  识别锚点  >  面部骨相（脸型/五官结构/颧骨与下颌）  >  具体取值（发色/肤色/材质/颜色）  >  装饰性细节
```

举例：清单给了「清冷、克制」，就**不要**补一张圆润娃娃脸配暖甜配色 —— 先让气质立住，再在它兼容的范围内取骨相与配色。反过来，清单明确写了的任何一项都压过气质，**硬事实永远第一**。

## 逐层维度（模板里写死的展开顺序）

**人物（六层）** 性别与年龄段 → 身高与体型 → 外貌特征（脸型：含**颧骨高低与下颌线走向** → 五官：眉形与眉头间距、眼型与眼距、鼻型、唇形与唇角走势、瞳色 → **面部张力（气质的落点）** → 皮肤 → 发型发色）→ 识别锚点（2~5 个）→ 详细服装（内搭 → 上装 → 下装 → 腰饰 → 腿饰/袜 → 鞋 → 配饰，每件给全 **款式＋颜色＋材质＋版型＋装饰细节**）→ 妆造与长期配饰

> **气质**（来自提取阶段的「气质」字段）：只允许落成**看得见的静态生理结构**，一共四处 ——
> ① **眉眼**：舒展还是收拢、眉头间距宽窄｜② **唇角**：平直还是自然微扬｜③ **咬肌与下颌**：放松还是绷住｜④ **目光**：聚焦有温度还是松散疏离、习惯直视还是习惯低垂。
> 写法举例：清冷克制 → 「眉眼间距舒展、眉头平直不聚、唇角自然平直、下颌咬肌放松、目光平稳疏离」。
> **这是长相与整体感觉的一部分，不是情绪** —— 禁止写成情绪词（愤怒/委屈/开心）、表情动作（皱眉/瞪眼/大笑/撇嘴）与台词。清单没给气质时，按身份与穿着自然带出一个不抢戏的底色。

**场景（七层）** 空间类型与用途 → 时代与地域 → 尺度与结构 → 地面/墙面/顶面材质 → 固定物件位置与朝向 → 光线与色彩基调 → 使用痕迹

**道具（六层）** 用途与整体轮廓 → 各面差异 → 尺寸与比例参照 → 材质纹理与颜色光泽 → 结构细节 → 磨损与当前形态

> 版式（四联设定图 / 空间全景 / 道具三视图）、画风、画质、**媒介质感**（纸张颗粒、网点、笔触这类）、姿态、机位**一律不写**，由「共用属性」与「版式」设置在生图前拼接。唯一例外：状态名含「机位图」的条目照旧自带九宫格版式。
>
> ⚠️ **不要把媒介质感写成固定尾句**（2026-10-07 修正）：此前模板要求「每条带 1 个媒介质感锚」，结果每条资产提示词末尾都是同一句「带有轻微漫画杂志印刷质感」—— 既是固定尾段，也与共用属性重复。该规则已删除，去 AI 味只保留「主体自身的具体瑕疵」。

## 样例：同一套清单，新模板产出长什么样

### 人物

> 林知夏，女，十六七岁的高中生，身高约 160 厘米，偏瘦的少女体型，约六头身，骨架纤细、肩膀窄。鹅蛋脸、颧骨平缓不外扩、下颌线柔和收窄；眼睛大而圆、瞳色浅褐、双眼皮偏窄，眉形自然略平、眉尾略散，鼻头小而圆，唇形饱满、唇色淡粉；**眉眼舒展、眉头平直不聚、唇角自然平直微欠上扬、下颌咬肌放松、目光平稳而略低垂**；脸颊两侧横向分布浅粉晕，鼻梁右侧有一粒小痣；肤色偏冷白，鼻翼与额角能看见细小毛孔；深棕色短碎发、自然中分，发丝略微凌乱翘起，额前几缕较长碎刘海，鬓角贴耳。识别锚点：深棕色短碎发＋脸颊横向粉红晕＋鼻梁右侧小痣。内搭白色棉质背心，圆领、肩带略窄；上装是天蓝色宽松短袖 T 恤，纯棉汗布，罗纹圆领、袖口轻微起皱，胸前印一只白色卡通恐龙；下装为卡其色宽松工装短裤，斜纹棉布，正面两个对称贴袋、袋盖带金属按扣，裤脚散口微卷；腿上白色中筒袜，袜口一道蓝色细边，右脚那只略微松垂；脚穿白蓝拼接厚底运动鞋，白色合成革配蓝色织物、魔术贴搭扣、鞋底厚约 4 厘米，鞋头一处浅磨痕。左手腕一条红色细编绳，素颜加淡粉色润唇膏。

上面加粗的那句就是「气质」的落地形态 —— 对应提取阶段的字段行 `- 气质：安静、内敛`。它取代了旧写法「性格安静慢热，神情偏淡」，因为旧写法里的「神情偏淡」会被生图读成一张**当场的表情**，而新写法是**长相的一部分**（五官的松紧与间距），跨状态不变、不会随剧情情绪漂走。

### 场景

> 南山中学旧教学楼三层的横向走廊，2000 年代中国南方城市的县城中学，课间与放学时段的学生通行空间。走廊宽约 2.4 米、长约 30 米、层高 3.2 米，右侧一整排开向操场的大窗、左侧是教室门与后墙，尽端有楼梯间形成纵深消失点。水磨石地面，灰白底嵌深灰多边形石粒，靠窗一侧被踩出一条约 40 厘米宽的暗色磨痕带；墙面涂半截墨绿色墙裙、上半为泛黄的乳白涂料，乳白部分有若干翘皮与手印；顶面为预制板拼接的白色天花板，外露两根冷白色日光灯管与一台深灰色噪声吊扇，灯管一侧积了薄灰。固定物件：右侧窗台高约 0.9 米、窗框为白色铝合金推拉扇、约六扇一组，玻璃下半部贴有不透明白膜；左侧教室门为深棕油漆木门、门上嵌一块 30×20 厘米的玻璃观察窗，门侧墙面挂一块深绿布面公告栏、四周包铝边；走廊尽头立一块蓝底白字的“高三（2）班”门牌。光线：下午四点半，西南侧窗户平行的低角度日光斜照进来，在地面拉出等距的长条光斑，光质偏软、色温约 4500K、中等强度，走廊内侧靠墙处形成一片比外侧暗两级的阴影。色彩基调是低饱和的灰绿与乳白，整体略褪色。使用痕迹：窗台上一处圆形水渍、墙裙下缘被书包蹭出的黑色划痕、楼梯口地砖缺了一角、吊扇叶片边缘有陈年积灰。

### 道具

> 一本硬壳练习册大小的旧笔记本，用于记录手工账目，合上时整体呈 2:3 的竖长方形。正面为深蓝色漆布硬壳，中央压印一枚圆形校徽、四角包磨损发白，靠书脊处有两条平行的竖向压槽；背面平整无饰，只有右下角一块约 4 厘米的深褐色茶渍；书脊正面能看到三枚米黄色棉线装订结、线头略微起毛；俯视（顶部）为约 2 厘米厚的纸叠，切口泛黄、靠前端有几页卷角，夹着一支削短的铅笔与一张对折的收据角。尺寸：长 21 厘米、宽 14 厘米、厚 2 厘米，摊在成人手掌上略短于小臂一半。材质与表面纹理：漆布外壳半哑光、经纬布纹清晰可见并有多处细裂纹，内页为泛黄的胶版纸、纤维略粗糙。结构细节：书脊棉线装订、前衬页写有钢笔手写姓名、扉页贴一张方形成绩贴纸。磨损与当前形态：八成旧的常用品，边角磨圆、外壳有零星白色刮痕与一处压折，整体平整无破损。

## 外部方法论迁移：`character-casting-studio`（2026-10-07）

来源：[dacnay816y62-hub/character-casting-studio-skill](https://github.com/dacnay816y62-hub/character-casting-studio-skill)
—— 写实人物 casting 设计 skill。它的**摄影层**（蜡像感、白平衡、焦段、毛孔尺度）与本项目无关（画风由共用属性给），
但它的**人物设计层**有 5 条可直接搬到条漫上。

### 搬过来的 5 条

| 该 skill 的做法 | 在本项目的落点 |
|---|---|
| **气质是第一等字段，且优先于骨相**：`temperament > identity memory anchors > bone structure > texture > polish` | 新增【补全的取舍顺序】（两个模板都写）；气质排在骨相之前 |
| **气质不是形容词，是「面部松弛或紧绷感」**（面部结构 8 项之一） | 提取侧「面部张力」并入第 3 维；生图侧「气质四处静态落点」；口径从「化成静态气质」升级为「落成看得见的静态生理结构」 |
| **面部结构 8 项**：脸型 / 眉 / 眼 / 鼻 / 唇 / **下巴** / **颧骨** / 面部张力 | 提取侧第 2 维补「颧骨的高低与位置、下颌线的走向与宽窄」；生图侧外貌特征层同步补 |
| **身份差异矩阵**：相邻人物至少改 5 维，禁止整批共用同一套取值（`not sisters, not twins`） | 原「剪影可辨与体型差」（只错开身高/体型两维）**升级为「人物差异矩阵」**：两两至少 5 维不同，并列出可用的 12 个维度 |
| **生活痕迹**：从一个角色的视线、面部张力、仪容、姿态、服装逻辑读出人生 | 本项目已有（去 AI 味的不完美细节：人物 ≥2 项 / 场景 ≥3 项 / 道具 ≥2 项）。**该 skill 的「媒介质感锚」不采用** —— 它是每张图必带的同一句话，属固定尾段，且与本项目「媒介质感归共用属性」的分工冲突 |

### 明确**不搬**的两类

1. **摄影/渲染类硬规则**：蜡像感、白平衡、`no yellow cast`、85–105mm 焦段、上下分棚、白底、商业完成度 ——
   这些属于**画风与拍摄规格**，在本项目里是「共用属性」的职责，写进模板会与共用属性打架。
2. **素材驱动与版权规则**：三分类素材包、source map、去身份化、不得复刻明星 ——
   本项目是原创小说转漫画，没有真人参考图，本节无落点。

### 一处**刻意不照搬**的地方

该 skill 把 `体态张力`（肩背松弛/端直）也算气质落点，本项目**不采用** —— 人物版式统一规定 A-POSE，
再写体态松紧会与版式打架。所以气质只落**面部四处**（眉眼 / 唇角 / 咬肌与下颌 / 目光），不碰躯干与四肢。
