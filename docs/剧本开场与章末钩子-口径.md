# 剧本「开场与收尾」口径（爆款开头 + 章末留人）

> 配套改动（2026-10-07，用户实报要求）：
> **「最开始把小说的爆点展示出来吸引人，结尾留足悬念」**。
> 模板正文：`src/modules/comic/services/promptTemplateRegistry.ts` 的 `script`。

## 一句话口径

**开场把最强的砸出来，章末不许收干净。** 中间每一场留一个小问题，每 3~5 场给一次爆点。

## 三层各自管什么（重要：钩子不是一个模板能装下的）

| 位置 | 剧本（章级） | 分镜（页级） | 画面描述（格级） |
|---|---|---|---|
| **开场** | 爆点前置／危机切入｜禁铺垫 | 按剧本顺序画，不受影响 | 首屏大画面（既有规则） |
| **中段** | 每 3~5 场一个爆点 | 每 3~5 页一个信息爆点（既有） | 每页末格留牵引力（既有） |
| **章末** | 六类钩子选一｜禁收干净 | **不写钩子** | **章末页强化（新增）** |

⚠️ **分镜层刻意不写钩子**：`备注` 会被 `cellScanText` 扫描，钩子里提到角色名会误报「未绑定」。测试里有断言锁死（`expect(storyboard).not.toContain('页尾钩子')`）。

## 研究依据（短剧 / 漫剧 / 条漫三个方向的共性）

| 结论 | 出处共性 |
|---|---|
| 黄金 3 秒：开场不铺垫，直接甩冲突／背叛／打脸／悬念 | 漫剧拆解 100 条，**95 条前 3 秒都是「强冲突画面 + 一句悬念台词」** |
| 卡点位置：在危机爆发前／真相揭露前／反转那一瞬切断 | 小说转漫剧「三步拆解法」 |
| 首尾双钩子：开头最激烈的冲突留人，结尾悬念勾人 | 短剧四维技巧 |
| 钩子密度：每 30 秒一个小钩子，每 3 集一个闭环 | 老编剧的钩子设计核心 |
| 钩子要与下一集爽点强关联，不是空泛的「且看下回分解」 | 同上 |
| 条漫特有：首屏 hook + **话末卡点（最后 3~5 格，决定付费转换）** | 条漫分镜 5 大原则 |

## 一、开场：三条硬约束（逐条都有具体后果）

前置写法：`- 钩子：开场·前置｜取自第 N 场｜只呈现冲突的入口，不揭示结果`
不前置写法：`- 钩子：开场·切入｜<本场第一件事>`

| 约束 | 违反后果 |
|---|---|
| **不得新增原文没有的事件** | 模型会为了「更炸」自己编一个事故，直接篡改原著 |
| **只给入口，不给答案** | 揭晓一起前置 → 后面揭晓时读者已经知道了，爆点全废 |
| **不得跨越服装／时期的状态切换点** | 前置片段若处于已换装状态 → 第 1 格要声明一个后面的资产状态，**下游分镜判断不出来**（这是前置方案唯一真正的坑） |

前置整章最多一次。本章最强瞬间本来就在开头时，直接「切入」即可，不强行前置。

## 二、章末：六类钩子 + 两条禁令

**六类钩子**（必须原文支撑得住）：危机降临｜真相前一秒｜反转暗示｜新威胁入场｜倒计时

**禁令一：禁止把情绪收干净。** 不得以总结、抒情、平静的日常、环境空镜、问题已经解决、情绪落地收尾。最后一场的「剧情目的」**必须包含「高潮」或「转折」，不得只写「收束」**（旧模板的 `收束` 取值等于在鼓励把章末写"收"掉）。

**禁令二：钩子只调落点，不调内容。** 一字不改原文的台词与事件，只决定「停在哪一拍」。原文本身平静时，把末拍停在**平静之下最不对劲的那一处**（一个不该有的眼神、一件放错位置的东西、一句答非所问的话）——不要自己编一个事故出来。

**钩子必须是画得出来的画面**：

- ✅「他推开门，屋里的灯是亮的」
- ❌「气氛变得紧张」「一种不祥的预感涌上来」

## 三、字段契约

`- 钩子：` 已进入剧本字段表，位置在「场景」之后：

```
场景 / 钩子 / 剧情 / 人物 / 动作 / 情绪 / 对白 / 旁白 / 心理外化 / 声音 / 剧情目的
```

⚠️ **只有第 1 场与最后一场写，其余场景整行省略。** 这是防「每场都挂一句钩子」退化成固定尾段 —— 本项目已经因为「每条都要带 X」踩过一次（见方案文档 §19 媒介质感锚）。

## 四、样例（同一章，改前 / 改后）

假设本章原文顺序是：① 她在食堂被同学议论 → ② 回家发现母亲在翻她的书包 → ③ 她冲出去，在巷口撞见哥哥和一个陌生人交接东西。

**改前（旧模板会这么写）**：

```
## 场景 1
- 场景：学校食堂 中午 阴天，窗外光线均匀偏冷
- 剧情：林知夏端着餐盘在角落坐下，听见邻桌同学低声议论她家里的事。
- 情绪：压抑、难堪
- 剧情目的：铺垫
```

> 问题：开场是一场「日常 + 环境交代 + 被议论」，三秒留不住人；信息密度低，读者看不到"这一话要看什么"。

**改后（新模板）**：

```
## 场景 1
- 场景：老巷口 黄昏 低角度残阳斜照，雨后的地面反着橙红碎光
- 钩子：开场·前置｜取自第 3 场｜只呈现冲突的入口，不揭示结果
- 剧情：一只旧铁盒从陌生人手里递出，哥哥伸手接住，指尖在盒盖上顿了一下；巷口拐角处，林知夏僵在原地，书包带从她手里滑落。
- 情绪：错愕、被排除在外
- 心理外化：她的手指收紧又松开，喉咙动了一下没出声（心理外化）
- 动作：陌生人把盒子往前一推，哥哥低头接过，两人同时侧头看向巷口方向
- 声音：“咔哒——”（盒扣扣上），随后是雨后屋檐滴水的零星落点
- 剧情目的：转折
```

```
（……场景 2、场景 3 按原文顺序照写……）

## 场景 4
- 场景：林知夏的房间 深夜 只开一盏床头灯，暖黄低强度，光只够照亮桌面一角
- 钩子：真相前一秒｜她终于打开那只铁盒，里面不是钱，而是一叠写着她名字的旧试卷
- 剧情：她把铁盒放在桌上，犹豫几秒后掀开盒盖，整个人定住。
- 情绪：难以置信
- 心理外化：她的瞳孔骤缩，呼吸停在半口上（心理外化）
- 动作：掀盖的手悬在半空，没有再往里翻
- 剧情目的：高潮＋转折
```

> 改后做了什么：**只改落点**。场景 1 的内容取自原文第 ③ 段（真实存在，未改写），只提前呈现「递盒子」这一拍，没交代盒子是什么；末拍停在**打开盒子、看到内容、没再往下翻**的瞬间 —— 盒子里的东西原文写了，但读者还看不到，这就是「真相前一秒」。

## 五、生效两步

1. **设置页 → 提示词模板 →「长篇章节漫画剧本」→「填入推荐模板」**（存量模板优先，不点不生效）。
2. 画面描述侧同改，**「分镜画面描述」与「分镜画面描述（整章一次生成）」两个都要点一次**。
3. 存量剧本需要重新生成才会带上开场与钩子。
