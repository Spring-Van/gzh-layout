# 长篇故事 · 提示词模板全景梳理（仅分析，未改代码）

> 分析范围：漫画工作台 → 长篇故事（LongProject）全管线。
> 涉及模板类型（TemplateType 中共 8 种，长篇故事使用其中 6 种；`story`/`style` 属于其它工作流）：
> `analysis` / `script` / `storyboard` / `extract` / `asset-prompt` / `panel-prompt`

---

## 一、六个模板使用环节总览

| # | 环节 | 模板类型 | UI 入口（选择模板的地方） | 拼装函数（文件） |
|---|------|---------|--------------------------|------------------|
| 1 | 原文分析 | `analysis` | LongProject.vue「原文」页签底部 PromptRunBar | `buildAnalysisPrompt`（chapterDocService.ts） |
| 2 | 漫画剧本 | `script` | LongProject.vue「剧本」页签底部 PromptRunBar | `buildScriptPrompt`（chapterDocService.ts） |
| 3 | 分镜生成 | `storyboard` | LongProjectStoryboardTab.vue 右栏「分镜内容」PanelContentEditor 的 PromptRunBar | `buildStoryboardPrompt`（storyboardService.ts） |
| 4 | 资产提取 | `extract` | LongProjectStoryboardTab.vue 顶栏「提取资产」PromptRunBar | `buildAssetExtractionPrompt`（assetExtractionService.ts） |
| 5 | 资产绘画提示词 | `asset-prompt` | LongProjectAssetWorkbench.vue 弹窗（AssetPromptGenerateModal：批量一次性 / 批量逐条）+ 单条重写弹窗 | `buildAssetPromptPrompt`（批量一次性）/ `buildSingleAssetPrompt`（逐条与单条）（assetPromptService.ts） |
| 6 | 分镜画面描述 | `panel-prompt` | LongProjectStoryboardTab.vue 画面描述推导弹窗（PanelPromptGenerateModal：单镜 / 批量） | `buildPanelPromptPrompt`（panelPromptService.ts） |

**模板选择的默认值策略**（各处一致）：取该类型下 `sortOrder` 最小的第一个模板；模型默认取第一个 LLM 类模型。分镜画面描述环节多一层兜底：模板 id 为空或未命中时，使用内置 `DEFAULT_PANEL_PROMPT_TEMPLATE`。

**发送前确认机制**（所有环节一致）：PromptRunBar / 生成弹窗点击执行 → 回调 `buildPrompt()` 生成最终提示词 → 勾选「发送前确认」则弹 PromptPreviewDialog 可临时编辑 → 以（可能已编辑的）最终文本执行，并持久化到对应 run 的 `prompt` 字段（失败重试沿用上次 prompt，不再重新拼装）。

## 二、各环节变量明细

### 1. 原文分析（analysis）

| 变量 | 含义 | 来源 |
|------|------|------|
| `{{chapter_content}}` | 章节原文（当前编辑草稿） | LongProject.vue `draftContent` |

- 末尾固定追加**系统输出协议**：中文 Markdown、`## 人物 / ## 场景 / ## 道具 / ## 事件与时间线…` 小节组织。
- 设置页提供「填入推荐原文分析模板」（`DEFAULT_ANALYSIS_TEMPLATE`），已含全部变量。

### 2. 漫画剧本（script）

| 变量 | 含义 | 来源 |
|------|------|------|
| `{{chapter_content}}` | 章节原文 | `draftContent` |
| `{{analysis}}` | 本章原文分析结果（**上一环节产物**） | `analysisDoc.content` |

- 末尾固定追加**系统输出协议**：`## 场景 N` 组织，字段行 `- 属性名：内容`。
- UI 关联提示：剧本页签顶部在分析为空时显示警示条（无分析仍可生成，变量/追加点会体现「尚未生成」）。
- 设置页推荐模板（`DEFAULT_SCRIPT_TEMPLATE`）已含全部变量。

### 3. 分镜生成（storyboard）

| 变量 | 含义 | 来源 |
|------|------|------|
| `{{script_content}}` | 漫画剧本（**上一环节产物**；无剧本时以章节原文兜底 + toast「将以原文兜底」） | `scriptDoc.content`，兜底 `chapter.content` |
| `{{analysis}}` | 原文分析（辅助上下文，可选） | `analysisDoc.content` |

- ⚠️ **发现不一致**：设置页「填入推荐分镜模板」的推荐文案（TemplateEditorForm.vue `recommendedStoryboardPrompt`）末尾使用的是 `{{chapter_content}}`，而 `buildStoryboardPrompt` 只识别 `{{script_content}}` / `{{analysis}}`。后果：
  1. `{{chapter_content}}` 占位符**原样保留**发给模型（不会被替换）；
  2. 由于 `{{script_content}}` 不存在，剧本内容改为以 `【漫画剧本】` 追加在模板末尾——原文实际没有注入到模板预留位置。
- 末尾固定追加**系统输出协议**：`## 分镜 N` + 字段行（画面/镜头必填，对白/旁白/绘画提示词/出场资产可选）+ 拆镜规则（一场景 3~8 镜等）。
- 产物解析 `parseStoryboardResponse` → panels；旧模板若输出「出场资产」行，按资产库做名称匹配回填绑定；重跑时按 order 迁移 panelArtworks（内容变了标记 stale）。

### 4. 资产提取（extract）

| 变量 | 含义 | 来源 |
|------|------|------|
| `{{chapter_content}}` | 章节原文 | `chapter.content` |

无变量的**上下文追加**（不走变量，非空即追加到模板后）：

| 追加块 | 内容 | 前后关联 |
|--------|------|---------|
| 【原文分析】 | 环节 1 产物 | 管线上游 |
| 【漫画剧本】 | 环节 2 产物 | 管线上游 |
| 【本章分镜概要（已确定会被绘制的画面）】 | 环节 3 产物，每镜一行 `分镜N：画面` | 管线上游；辅助判断资产价值（出现次数） |
| 【项目已有资产】 | 项目资产库列表（名称+类型+已有视觉状态名）+ 状态名沿用规则 | 跨章节连续性 |

- 末尾固定追加**系统固定输出协议**：`# 人物 / # 场景 / # 道具` → `## 资产名` → `### 视觉状态：状态名`，块内字段：视觉描述、状态标签、绘画提示词。
- 解析：先按中文 Markdown 报告解析，失败兜底旧 JSON 协议；与已有资产做名称匹配（决策 merge/create）、状态名多级模糊匹配。
- 确定性统计：候选名在本章分镜文本中出现次数（不调模型），供审核页参考。
- ⚠️ **发现（残留字段）**：`PromptTemplate.assetExtractionConfig`（注释称"仅资产提取模板使用"）在运行时仅被**原样存入** run.extractionConfig（LongProjectStoryboardTab.vue:596），**拼装提示词时完全未消费**——属于已废弃/未接线的字段。

### 5. 资产绘画提示词（asset-prompt）— 两种拼装路径

**A. 批量·一次性发送 `buildAssetPromptPrompt`**（一份清单一次请求，结果需程序解析回填）

| 变量 | 含义 | 来源 |
|------|------|------|
| `{{assets}}` | 待生成状态清单（每状态一行：序号｜资产名｜状态名｜资产描述｜视觉描述｜固定特征｜attributes 前 8 项） | 资产库中选中范围的目标状态（仅缺提示词 / 全部） |
| `{{style}}` | 风格上下文（整体画风 + 共用提示词块 description 按 sortOrder） | `buildStyleContext(imageGenConfig.sharedBlocks, comicConfig.paintingStyle)` |
| `{{target_model}}` | 目标生图模型名 | 资产生图配置里的 imageModelId → name |

**B. 批量·逐条发送 / 单条重写 `buildSingleAssetPrompt`**（每状态一次请求，结果直接取全文回填）

| 变量 | 含义 | 说明 |
|------|------|------|
| `{{assets}}` | 单个状态的信息块（资产/类型/描述/固定特征/状态名/视觉描述） | 与 A 的清单格式不同 |
| `{{style}}` | 风格上下文 | 同 A |

- 路径 B **不支持** `{{target_model}}`；不走模板时会用内置默认指令（含固定输出要求）。
- **输出协议优先级**（`applyOutputProtocol`）：模板自定义 `outputProtocol` > 批量一次性场景的系统兜底解析协议（`【资产名｜状态名】提示词` 逐条格式）> 不附加任何限制。
- ⚠️ **发现（{{style}} 重复注入）**：路径 A 中若模板含 `{{style}}` 且风格上下文非空——变量被替换为风格文本后，函数末尾**又会追加一次**【风格上下文】块（assetPromptService.ts:158 替换 + :168 无条件追加）→ 风格内容在提示词里出现两遍。路径 B 分支判断正确，无此问题。
- 回填解析三级兜底：括号名字协议 → 行首名字协议 → 「状态N」序号协议；全部失败时报错（自定义协议与解析格式不匹配时给出专门提示）。

### 6. 分镜画面描述（panel-prompt）

| 变量 | 含义 | 来源 |
|------|------|------|
| `{{panel_content}}` | 当前分镜画面内容 | panel.content |
| `{{shot}}` | 镜头类型 | panel.shot |
| `{{prev_panels}}` | **前文滑动窗口**：前 2 镜（DEFAULT_PREV_PANEL_WINDOW）的分镜 + 已推导画面描述；批量推导时随进度动态刷新 | panels + panelArtworks.imagePrompt |
| `{{chapter_outline}}` | 本章分镜概要（每镜一行） | `buildChapterOutline(panels)` |
| `{{assets}}` | 本分镜绑定资产的视觉设定（状态名/视觉描述/**已生成的资产绘画提示词**/固定特征） | 环节 5 产物，经 assetBindings 解析 |
| `{{style}}` | 风格上下文 | 同环节 5 |
| `{{target_model}}` | 目标生图模型名 | 生图配置 imageModelId → name |

- 批量推导按分镜顺序串行执行（每镜一次调用），前文窗口自动带上前面新推导的描述——**这是提示词前后关联最强的环节**。
- 输出协议：仅模板自定义 `outputProtocol`；未定义则不附加任何限制（结果直接全文回填 artwork.imagePrompt，无需解析）。
- ⚠️ **发现（{{style}} 重复注入，同环节 5 路径 A）**：panelPromptService.ts:89 变量替换 + :104 无条件追加。
- 模板未选/未命中 → 内置 `DEFAULT_PANEL_PROMPT_TEMPLATE`（无变量，靠追加【当前分镜】信息块工作）。

## 三、提示词前后关联链（管线依赖图）

```
章节原文
   │
   ▼ [1 analysis: {{chapter_content}}]
原文分析文档 ──────────────┐
   │                      │
   ▼ [2 script: {{chapter_content}} + {{analysis}}]
漫画剧本文档 ──────────────┤
   │                      │
   ▼ [3 storyboard: {{script_content}}(无剧本→原文兜底) + {{analysis}}]
分镜 panels ───────────────┤ (分镜概要)
   │                      │
   ▼ [4 extract: {{chapter_content}} + 追加:分析/剧本/分镜概要/已有资产]
资产候选 → 人工审核入库 ────┤
   │                      │
   ▼ [5 asset-prompt: {{assets}}(状态清单/单状态) + {{style}} + {{target_model}}]
资产视觉状态 imagePrompt ──┤ (进入环节6的 {{assets}} 与生图参考图)
   │                      │
   ▼ [6 panel-prompt: {{panel_content}} + {{shot}} + {{prev_panels}}(前2镜)
              + {{chapter_outline}} + {{assets}}(绑定资产含环节5提示词)
              + {{style}} + {{target_model}}]
分镜画面描述 → 批量生图（共用块参考图也在此参与）
```

横向贯穿项：
- **风格上下文 `{{style}}`**：由「样式模板/共用提示词块 + 项目画风」实时构建，环节 5、6 共用同一口径（`buildStyleContext`）。
- **目标生图模型 `{{target_model}}`**：环节 5（仅批量一次性）、环节 6 支持，让提示词面向具体生图模型优化。

## 四、"没插入变量"的处理方式汇总（逐函数对比）

| 拼装函数 | 变量缺失时的处理 |
|---------|-----------------|
| `buildAnalysisPrompt` / `buildScriptPrompt`（共用 `applyVariables`） | 变量在模板中→原地替换；不在→内容非空则以 `【标签】` 追加到模板末尾。`{{analysis}}` 存在但值为空→替换为占位文字「（本章尚未生成原文分析）」；`{{analysis}}` 不存在且值为空→完全不追加 |
| `buildStoryboardPrompt` | `{{script_content}}` 不在→追加【漫画剧本】（始终追加，剧本是主输入）；`{{analysis}}` 不在→仅非空时追加【原文分析（辅助上下文）】；`{{analysis}}` 在但为空→替换为「（本章尚未生成原文分析）」 |
| `buildAssetExtractionPrompt` | `{{chapter_content}}` 不在→追加【章节原文】；分析/剧本/分镜概要/已有资产四个上下文**不走变量**，非空即追加 |
| `buildAssetPromptPrompt`（批量一次性） | 三个变量**任一存在**→视为"有变量"，只做替换不追加清单；**全都不存在**→追加【待生成状态清单】。风格上下文**非空时无条件再追加**【风格上下文】→ 与 `{{style}}` 替换重复 ⚠️ |
| `buildSingleAssetPrompt`（逐条/单条） | `{{assets}}` 不在→追加【待生成状态】；`{{style}}` 不在且风格非空→追加【风格上下文】（判断正确，不重复） |
| `buildPanelPromptPrompt` | 七个变量**任一存在**→只替换；全不存在→追加【当前分镜】信息块。风格上下文**非空时无条件再追加**【风格上下文】→ 与 `{{style}}` 替换重复 ⚠️ |

变量**有占位但值缺失**时的填充词（发给模型的兜底文案）：
- `{{shot}}` / `{{target_model}}` → 「未指定」
- `{{style}}` → 「无特殊风格要求」
- `{{prev_panels}}` 空窗口 → 「当前是本章第一个分镜，无前文画面。」
- `{{assets}}`（分镜无绑定）→ 「本分镜无绑定资产。」
- `{{analysis}}` → 「（本章尚未生成原文分析）」
