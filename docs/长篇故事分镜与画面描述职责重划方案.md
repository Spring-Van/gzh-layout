# 长篇故事：分镜 / 画面描述 职责重划方案

> 状态：**已拍板并落地**（2026-09-27，结论与改动见第八节；要素齐全化追加见第九节）
> 范围：`storyboard` / `panel-prompt` / `panel-prompt-chapter` / `script` 四个模板的职责边界、规则库落地位置、
> 与资产绑定（参考图清单）的联动口径，以及「一页漫画全部要素」的传递链路（第九节）。
> 依据：`docs/长篇故事剧本与分镜格式定稿.md`（规则库摘要）、`.workbuddy/memory/topics/panel-prompt.md`（09-19 口径）、
> 现有代码（`promptTemplateRegistry.ts` / `panelPromptService.ts` / `storyboardService.ts`）。

## 一、结论摘要

**你的感觉是对的，但错位不在"分镜写了绘画参数"**——分镜模板已经明确禁止写风格/颜色/占比/景深/分格结构/气泡位置。
真正的错位是两条：

1. **分镜的「画面」字段定义本身就是视觉内容**（"构图 + 人物位置 + 动作 + 环境 + 关键细节，30~80 字"），
   而画面描述层的写作要求是"人物位置与动作、表情、场景环境、光线氛围" —— **两层写的是同一批东西**，
   所以画面描述只能把「画面」字段换词重写一遍。
2. **画面描述层没有承接规则库**：文档里写着"占比铁律 / 浅景深 / 6 种分格结构 / R13·R14 / 气泡规范由画面描述层落"，
   但 `panel-prompt` 推荐模板只有 4 条写作要求，**一条漫画规则都没有**。规则只活在文档里，从未被执行。

一句话职责划分（建议）：

| 层 | 回答的问题 | 一句话口径 |
|---|---|---|
| 剧本 | 这一章每一场戏怎么演 | 内容与目的 |
| **分镜** | 这一页有几格、每格什么镜头、**发生了什么**、说什么 | **画什么**（叙事事实 + 台词 + 资产声明） |
| **画面描述** | 这一格**具体怎么画出来** | **怎么画**（视觉参数：结构/占比/景深/光线/视角/气泡 + 画面落位） |

## 二、现状诊断（逐条给证据）

### 2.1 分镜层：字段定义越界，但字段本身没被禁用

`promptTemplateRegistry.ts` → `storyboard` 推荐模板：

- 「画面」= *"构图、人物位置、动作、环境、关键细节，30~80 字"*；
- 同模板结尾：*"不写绘画风格、颜色、人物占比、景深、分格结构、气泡位置——这些由画面描述环节按规则库处理"*。

**结论**：模型被要求"不写占比/景深/结构"，却又被要求写"构图、人物位置、环境、关键细节"——
这两件事在生图语境下是同一层的东西。于是分镜层自发把画面写到位，画面描述层无事可做，只能复述。

### 2.2 画面描述层：没有规则库，且自缚手脚

`panel-prompt` / `panel-prompt-chapter` 推荐模板的全部写作要求（现文）：

```
- 每格先写一行景别与镜头，再写画面内容：人物位置与动作、表情、场景环境、光线氛围…
- 与前文分镜保持画面连续…
- 严格基于给定信息撰写，不要补写原文没有的细节；不写对白与旁白…
- 不要输出参考图清单、图号、共用属性或全局画风。
```

两条硬伤：

| 硬伤 | 后果 |
|---|---|
| **零规则库** | 占比/景深/分格结构/视角一致性/气泡规范全部缺位，规则文档形同虚设 |
| **"严格基于给定信息，不要补写"** | 与"按规则落地视觉参数"直接冲突：规则要求的信息（占比、景深、气泡）输入里根本没有，又不许补 → 只能复述输入 |

### 2.3 实际传进画面描述层的输入（`panelPromptService.buildPanelInfoText`）

```
分镜序号 / 镜头 / 画面内容（页级 content）
分格详情：第N格 → 景别、镜头、画面、人物、出场资产、动作、表情、音效、光效、备注
分镜参考描述（旧描述，若有）
```

**注意**：`formatCellsForPrompt` 已经把**每格「出场资产」（资产名 + 状态名）**传给模型了。
也就是说"资产指代词典"其实一直在输入里，只是模板里没有任何一句要求模型**用它**。

### 2.4 画面描述的两个下游，口径必须同时满足

| 下游 | 口径 |
|---|---|
| **生成** | `composeFinalPrompt` = 前置共用属性 + 【动态参考图】（`图N = 资产·状态 + 用途句`）+ **描述** + 后置共用属性。描述是提示词的正文段 |
| **绑定** | **"描述即事实"**：`bindingScanPrompt(描述)` 被扫描，描述里出现的资产名/状态名 → 自动绑定 → 决定参考图清单。描述用代词或自造外观 → 绑定漏 / 与资产状态冲突 |

所以画面描述的写作规则**必须**同时服务这两件事：写清画面落位（喂生图）+ 写全资产名（喂绑定）。

## 三、职责重定义（建议采纳）

### 3.1 分镜层：从"画什么+怎么画"收窄到"画什么"

| 字段 | 现状 | 建议 |
|---|---|---|
| 景别 | 7 选 1（必填） | **不变**（画面描述层的占比/景深/焦段锚点） |
| 镜头 | 机位与运镜 | **不变**（锚点：机位、正反打、POV） |
| **画面** | 构图+人物位置+动作+环境+关键细节，30~80 字 | **改为「画面要点」**：这一格**发生了什么、看到什么关键信息**，30~60 字；**明确禁写**：构图、人物在画面中的位置与占比、光线方向与色温、景深、颜色、画风、气泡位置 |
| 人物 | 画面内角色名 | **不变**（绑定/气泡挂靠的候选名） |
| 出场资产 | `编号 资产名（状态名）` | **不变**（高置信绑定通道） |
| 动作 / 表情 | 10~25 字 | **不变**（叙事事实，画面描述层据此定人物动态与朝向） |
| 台词 / 心声 / 画外 / 旁白 | 四选一，带说话人 | **不变**（气泡/旁白框的输入：谁说话 → 气泡挂谁） |
| 音效 | 环境音与拟音 | **不变**（不进画面，留给后期/排版） |
| 光效 | 本格光线与明暗关系 | **保留但降级为氛围词**（如"暖黄顶灯、背景压暗"）；**光线四要素（方向/光质/色温/强度）由画面描述层补齐** |
| 备注 | 必须画出来的关键点 | **不变** |

> 这一刀的意义：分镜仍然"读者能看懂这一页画什么"，但不再替画面描述层写画面。

### 3.2 画面描述层：从"复述分镜"变成"落视觉参数"

新推荐模板结构（建议）：

```
【本镜输入】分镜（含每格：景别/镜头/画面要点/人物/出场资产/动作/表情/台词/光效/备注）

【绘画规则】（固定段落，用户可改）
1. 分格结构：按本页格数与剧情选结构 —— 单格满版 / 上下双格 / 左右双格 / 三格递进 / 不规则主从格；
   页内指定主格（情绪焦点最大），其余格为辅。
2. 人物占比（由景别决定，铁律）：
   远景 <20% ｜ 中景 40~60% ｜ 近景 60~80% ｜ 特写 >80%。
3. 景深：浅景深为默认（主体清晰、背景柔化）；仅交代环境的全景页可中景深。
4. 视角一致性（R13/R14）：面对面时不同格不重复同一正脸角度；POV 内容单独成格（不与"角色看"同格）；
   机位在同一页内保持轴线一致。
5. 光线：每格写全 方向 / 光质（硬·柔）/ 色温（暖·冷·具体 K 值）/ 强度；承接分镜「光效」并具体化。
6. 气泡与旁白框：谁说话 → 气泡挂在该角色头侧（避开脸部与关键表情），气尾指向说话人；
   旁白/心声用矩形旁白框贴页边；本格无台词则不画气泡。
7. 出场资产：用分镜里的**资产名**指代（不用"她/那个男人"）；**不描写其外貌、服装、发型、颜色**
   —— 这些由参考图承载，写多了必然与视觉状态冲突。
8. 连续性：与前一镜保持人物左右关系、服装状态、光线方向、场景细节一致。

【输出】逐格「第X格：」小节：结构/占比/景深/视角 → 光线 → 画面内容（人物位置与动态、表情、环境、关键细节）
```

要点：**规则库以"模板内的固定段落"落地**（用户可改），而不是藏在文档或共用属性里——
因为占比/景深/结构/气泡必须由模型逐格决定，无法在生图时统一施加。

## 四、与资产绑定的联动（三个改进点）

### 4.1 现行链路（无改动时的实际行为）

```
分镜「出场资产」声明（编号查表，高置信）
        └─→ panel.assetBindings ─→ 参考图清单 ─→ 图N = 资产（状态）→ 拼进生图 prompt
画面描述文本（名字扫描，兜底）
        └─→ syncBindingsAfterPromptWrite ─→ 同上
```

两条通道都进同一份绑定，**描述通道容易漏**（模型写代词/昵称），分镜通道最稳（编号查表）。

### 4.2 改进点

| # | 改进 | 做法 | 收益 |
|---|---|---|---|
| 1 | **描述必须使用资产名指代** | 写进画面描述模板规则（§3.2 第 7 条） | 描述通道的绑定不漏；同资产多状态时状态名也更稳 |
| 2 | **禁止在描述里改写外观** | 同上：外貌/服装/发型/颜色一律交给参考图 | 根除"描述写红裙、资产状态是白裙"这类矛盾 |
| 3 | **格级状态落位要一致** | 描述按格写；对齐输入的「出场资产」逐格状态（同页换装页 = 不同格不同状态） | 参考图清单按格出图（`图N … 第X格`）与描述指向同一状态 |

**不建议**重新引入 `{{参考图清单}}`（图号）到画面描述层：图号随共用属性图数量变化，
一旦进描述，换图/改顺序就要重跑全部描述 —— 这条 2026-09-19 已否决，本次维持。
但**资产名 + 状态名以"输入只读"的形式已经在分镜分格详情里**（§2.3），无需新增变量。

## 五、拍板点（4 项）

| # | 问题 | 选项 | 建议 |
|---|---|---|---|
| 1 | 分镜「画面」字段是否收窄为「画面要点」 | A. 收窄（禁写构图/位置/光线/占比）；B. 保持现状，只在画面描述模板里加"不要复述画面要点，要做视觉转译" | **A**（否则重复永远存在）；若担心分镜可读性下降，可取折中：保留"环境/关键细节"，禁"构图/位置/占比/光线" |
| 2 | 规则库放哪 | A. 写进 `panel-prompt` / `panel-prompt-chapter` 推荐模板正文（用户可改）；B. 新增独立变量 `{{绘画规则}}`；C. 放共用属性 | **A**（最小改动、可见可改；B 需要新增变量与设置页入口，C 无法逐格生效） |
| 3 | 气泡/旁白框由谁画 | A. 画面描述层写清位置，交给生图模型画；B. 画面描述不写气泡，由排版环节叠加；C. 描述层写"留白提示"，排版层再叠 | 需你定（见下"我的看法"） |
| 4 | 是否给画面描述层显式的「本镜出场资产（含格号）」变量 | A. 不加（分格详情里已有）；B. 加一个 `{{本镜出场资产}}` 汇总行（不含图号） | **A**（零改动；B 只在发现模型漏读分格详情时再补） |

**关于第 3 点的看法**：本项目的产物是"一张图 = 一页"，气泡若由生图模型画，位置必然随机、遮挡脸的概率高，
且后期改字要重画。若后续有排版环节（本项目本身就有公众号排版能力），建议 **C**：
画面描述里只写"本格上方/右侧留出气泡空间"，气泡本体在排版层叠加 —— 生图稳定、改字免重画。
若暂时没有排版环节，只能选 A，那就必须把气泡规范写细（挂谁、避开脸部、气尾指向）。

## 八、拍板结论与落地（2026-09-27）

### 8.1 拍板结果（对照第五章）

| # | 拍板点 | 决定 | 落地方式 |
|---|---|---|---|
| 1 | 分镜「画面」是否收窄 | **不收窄** | `storyboard` 模板与协议**零改动**；画面描述层的增量价值改由「规则参数 + 文字层」承载 |
| 2 | 规则库放哪 | **写进模板正文**（用户可改） | 两个画面描述推荐模板新增【漫画画面规则】固定段落 |
| 3 | 气泡/旁白框由谁画 | **生图模型画** | 新增【文字气泡与旁白框】段落，气尾指向按说话方式分派（含画外音不得指向画面内人物） |
| 4 | 是否新增变量 | **不加** | 分格详情已含资产名与台词，无 `{{本镜出场资产}}` 等新占位符 |
| 5 | 旁白是否要分析出来 | **要**（否则出的图读者看不懂） | 台词 / 心声 / 画外 / 旁白四类全部进入画面描述输入，并逐格转写为图上文字层 |

### 8.2 最终职责口径

| 层 | 写什么 |
|---|---|
| 分镜 | **画什么**：页内几格、每格 景别/镜头/画面（**保持现状**）/人物/出场资产/动作/表情/台词类/音效/光效/备注 |
| 画面描述 | **怎么画**：画面落位 + 漫画规则参数（分格结构、人物占比、景深、视角关系、光线四要素）+ **图上文字层**（气泡类型/位置/气尾指向/文字） |

画面描述不再靠改写分镜画面取得差异，而是靠「规则参数 + 文字层」这两块增量。

### 8.4 气泡规范（模板落地原文摘要）

| 说话方式 | 气泡形态 | 气尾指向 |
|---|---|---|
| 台词（对白，说话人在本格画面内） | 椭圆 | 尖端指向说话人嘴部／下颌 |
| 心声（内心独白） | 云朵边／波浪边 | 一串小圆点，指向说话人头部 |
| **画外**（说话人不在本格画面内） | 同对白椭圆 | **不得指向画面内的任何人物**（指过去会被读成他们在说话）；朝声源方向伸出画面（出画人物方向／门窗外／画框外缘），或改用无尾方角框并在框边注明声源 |
| 旁白（无人称叙述） | 方角矩形，贴画面左上或左下角 | 无气尾 |

位置与样式：气泡放说话人头侧或对侧留白区，不遮挡人物面部、表情与关键信息；同格多气泡按说话先后错开不重叠；细黑描边的白底／半透明底、横排中文。

### 8.5 遗留与风险

1. **绑定扫描会读到气泡文字**：`bindingScanPrompt` 返回整段 `imagePrompt`，气泡内台词含角色名时会进入绑定扫描（与分镜文本通道原有情况同类，此处只是多一次机会）。已把文字层统一为「文字气泡：」行首标记，将来需要排除时可按该标记切段。**本轮未改绑定扫描逻辑。**
2. **生图模型画气泡的现实损耗**：位置随机、遮挡脸、气泡内中文字形失真属预期内损耗，改字需重画。若体验不可接受，可切回「描述只写留白 + 排版层叠加气泡」（§5 第 3 点选项 C）。
3. **存量模板与存量数据**：推荐模板不覆盖用户模板，需在设置页对 `分镜画面描述` / `分镜画面描述（整章一次生成）` 点「填入推荐模板」；已生成的画面描述需「全部重新生成」才会带规则参数与文字层。

## 九、要素齐全化（2026-09-27 追加）

### 9.1 目标

最终生成的画面描述必须包含**这一页漫画的全部要素**：漫画排版、每格画面内容、漫画表现元素、音效拟声词、旁白、对话。

### 9.2 要素归属矩阵（谁产生 / 谁消费）

| 要素 | 产生层 | 现状 | 本次改动 |
|---|---|---|---|
| **漫画排版**（页面结构：单格满版 / 双格 / 三格 / 四格） | 分镜层声明 `panel.cellLabel` | ❌ 解析器存了但**从没传给画面描述模型** | `buildPanelInfoText` 输出 `页面结构：<标签>（本页 N 格）` |
| 每格画面内容（景别 / 镜头 / 画面 / 人物 / 动作 / 表情 / 光效 / 备注） | 分镜层 | ✅ 已传入 | 不变 |
| 出场资产（含视觉状态） | 分镜层 | ✅ 已传入 | 不变 |
| **对话 / 心声 / 画外** | 分镜层（剧本有逐字「对白」源） | ✅ 已传入 + 气泡规则已补 | 不变 |
| **旁白** | 剧本 → 分镜 | ⚠️ 剧本层无独立字段，旁白被折进「剧情」，分镜只能猜 | script 新增独立字段；storyboard 补【旁白怎么写】五条规则 |
| **音效拟声词** | 剧本「声音」→ 分镜「音效」 | ⚠️ 已传入，但没说哪些要画到图上 | storyboard 要求拟声词用引号写出；panel-prompt 要求把引号内拟声词画成图上艺术字 |
| **漫画表现元素**（速度线 / 集中线 / 情绪符号 / 气氛网点 / 留白） | 画面描述层（属于「怎么画」） | ❌ 规则库中完全没有 | panel-prompt 新增【漫画表现元素】段 |
| 文字层（气泡形态 / 气尾指向 / 位置） | 画面描述层 | ✅ 已有 | 补「拟声词不进气泡」分流 |

### 9.3 为什么不把旁白放到画面描述层做

| 要素 | 分镜层 | 画面描述层 |
|---|---|---|
| 全章视野 | ✅ 有（旁白是**节奏元素**，「短旁白页每章 3~6 页」需要跨页分配） | ❌ 逐镜作业，只看到本镜 + 前文 |
| 章节原文 / 漫画剧本 | ✅ 都是输入 | ❌ 没有 |
| 能否决定「这句旁白落在哪一页哪一格」 | ✅ 这正是分镜的职责 | ❌ 无权分配 |

结论：**旁白的「提取与分配」在分镜层，「画成什么形态」在画面描述层。** 但要让提取「准确」，必须在剧本层给旁白一个逐字出口——否则分镜拿到的只是一坨「剧情」文本，写出来的旁白是再创作而非继承。

### 9.5 遗留

1. **「分镜参考描述」会回灌旧输出**：`buildPanelInfoText` 末尾的 `分镜参考描述：<panel.imagePrompt>` 是上一版画面描述。它在「全部重新生成」时作为输入喂给模型，可能让模型沿袭旧写法、稀释本次新增的规则约束。**本轮未动**——如需彻底重生成，去掉这一行即可（一行改动）。
