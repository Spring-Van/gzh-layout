# 长篇工作台三项改造：章节起笔模式 / 资产顶级 tab / 资产提取优化

## Context

长篇漫画管线当前为「原文 → 分析 → 剧本 → 分镜（内嵌资产视图）→ 生图」。本次改造三个需求：

1. **章节起笔模式**：新建章节时可选「从原文开始」（现状）或「从剧本开始」（跳过原文直接写剧本）；后者隐藏主页面「原文」tab。
2. **资产提升为顶级 tab**：资产视图（提取/审核/生图工作台）目前嵌在「分镜」tab 内（pageTab 切换），迁出为与原文/剧本/分镜同级的顶级 tab，排在分镜右侧。
3. **资产提取优化**：提示词模板变量语义、拼接逻辑与兜底设计——核心是支持无原文（从剧本开始）章节的提取：底稿改为「原文优先、剧本兜底」。

关键前置事实（已核实）：
- stage 无任何 UI 展示（全库仅 2 处写入、0 处读取展示），顺序调整安全。
- `LongProjectAssetTab.vue` 文件名未被占用（panel-gen 下的是 `PanelGenAssetTab.vue`）。
- `LongProjectChapterDoc.source` 现为 `'llm' | 'manual'`。
- 验证命令：`pnpm typecheck`、`pnpm dev`。

## 需求 1：新建章节可选「从剧本开始」

### 数据模型（[types/index.ts](d:/xiang/gzh-layout/src/modules/comic/types/index.ts)）

- `LongProjectNode` 增加 `startMode?: 'source' | 'script'`；缺省视为 `source`（旧数据零迁移）。
- `LongProjectChapterDoc.source` 扩展为 `'llm' | 'manual' | 'handwritten'`（manual=外部 AI 粘贴导入，handwritten=本地手写）。

### 新建对话框（[LongProjectNodeDialog.vue](d:/xiang/gzh-layout/src/modules/comic/components/LongProjectNodeDialog.vue)）

- 仅 `nodeType === 'chapter'` 且**非重命名模式**时，显示「创作方式」单选组：
  - 从原文开始（默认）：粘贴小说原文，走完整管线。
  - 从剧本开始：跳过原文，直接编写/导入剧本。
- submit payload 增加 `startMode`。

### 主页面（[LongProject.vue](d:/xiang/gzh-layout/src/modules/comic/views/LongProject.vue)）

- `chapterTabs` 改为 computed：追加 `{ key: 'assets', label: '资产', icon: Boxes }`（需求 2）；当 `selectedChapter?.startMode === 'script'` 时过滤掉 source tab。
- `handleNodeDialogSubmit`：章节节点写入 `startMode`；创建后落 tab——script 模式进 `script`，否则 `source`。
- `selectChapter` 与章节切换兜底：activeTab 为 `source` 但章节为 script 模式时切到 `script`（分镜/资产保持常驻粘性，与现状一致）。

### 剧本 tab（[LongProjectScriptTab.vue](d:/xiang/gzh-layout/src/modules/comic/components/LongProjectScriptTab.vue)）

- 新增 prop `scriptOnly?: boolean`：
  - 左栏原文区显示占位说明卡（「本章从剧本开始创作，无需录入原文」），替代「（本章暂无正文）」。
  - 隐藏「分析缺失」黄条（script 模式无原文 → 无分析，提示无意义）。
- 空态增加「直接编写剧本」按钮（不限 scriptOnly，普通章节也可手写）：进入编辑模式空稿。顶部「编辑」按钮不再仅限 `scriptDoc?.status === 'completed'`——无 doc 且在手写状态也可编辑。
- `commitScriptDraft`：无 doc 时也 emit（见下条 upsert）。
- 手写徽标：`source === 'handwritten'` 显示「手动编写」，manual 仍显示「手动导入」。

### 剧本 upsert 与 stage 推进（[useChapterDocRun.ts](d:/xiang/gzh-layout/src/modules/comic/composables/useChapterDocRun.ts)）

- `saveDocContent` 由「仅更新已存在 doc」改为 **upsert**：无 doc 时创建 `{ status: 'completed', source: 'handwritten', prompt: '', sourceContent: 当前原文 }`。
- kind 为 `script` 且内容非空时，stage 只升不降推进到 `script-ready`（复用 stageOrder 判断）。

## 需求 3：资产提取模板 / 拼接 / 兜底优化

### 底稿兜底（[assetExtractionService.ts](d:/xiang/gzh-layout/src/modules/comic/services/assetExtractionService.ts)）

- 新增纯函数 `buildExtractionSourceText(original: string, script: string): string`：
  - 原文非空 → 原文；
  - 原文空、剧本非空 → 说明头（「本章从剧本开始创作，无原文；以下为漫画剧本全文，请以此作为提取底稿」）+ 剧本全文；
  - 均空 → 空串。
- `runExtraction` / `buildExtractPrompt`（迁入新资产 tab 后）统一用该函数组装 `章节原文` 变量值与 run.sourceContent。
- **提取按钮禁用条件放开**：`!(原文 || 剧本)` 才禁用（原为仅检查原文）；无原文时按钮 title 注明「将以漫画剧本作为提取底稿」。

### 数据与指令分离（[promptTemplateRegistry.ts](d:/xiang/gzh-layout/src/modules/comic/services/promptTemplateRegistry.ts)）

- `{{已有资产}}` 变量值**只保留资产清单**；「状态名必须与已有状态名完全一致」规则文本挪到 `OUTPUT_PROTOCOL_DEFAULTS.extract` 尾部（模板作者在设置页可见可改）。
- 变量注册表更新：
  - `章节原文` desc → 「当前章节的原文；本章从剧本开始（无原文）时自动以漫画剧本兜底」；emptyText → 「（本章尚未录入原文与剧本）」。
  - `已有资产` desc 同步微调（不再描述内嵌规则）。
- extract 推荐模板正文基本不动（规则已进协议）。

### 设置页协议提示（[TemplateEditorForm.vue](d:/xiang/gzh-layout/src/features/settings/components/TemplateEditorForm.vue)）

- 协议说明文案按模板类型区分：extract 提示「需保留 `# 人物 / # 场景 / # 道具 → ## 资产名 → ### 视觉状态：状态名` 标题结构，系统依赖该结构解析回填」；storyboard 提示「需保留 `## 分镜 N` 标题结构」；asset-prompt 维持现有文案；其余类型通用文案。

### 无分镜轻提示（[PanelGenAssetTab.vue](d:/xiang/gzh-layout/src/modules/comic/components/panel-gen/PanelGenAssetTab.vue)）

- info 视图顶部：`panels` 为空时显示提示条「本章尚未生成分镜：仍可提取资产，但候选无分镜出现次数，确认后也不会自动回填分镜绑定」。
