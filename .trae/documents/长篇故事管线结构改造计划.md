# 长篇故事管线结构改造 · 实施计划

## Context（背景与目标）

将长篇故事创作管线改造为清晰的四环节 AI 管线：**小说 → 原文分析 → 漫画剧本 → 分镜 → 资产提取 → 绘画Prompt → 生图**。

用户已确认的三个关键决策：

1. **保持独立生图页面**：主页面 tab 只保留 原文｜剧本；生图页面（现有路由 `/panel-gen/:projectId/:chapterId`）顶部新增 分镜｜资产 两个页面级 tab
2. **按新管线改造提示词组装**：分镜 = 剧本(主)+原文分析(辅)+分镜规则（不再依赖资产库）；资产提取 = 原文分析+剧本+分镜+提取规则（含分镜出现次数统计，确定性计算）；分镜的资产绑定改为资产确认后按文本自动回填（复用现有 `syncPanelsAutoBindings`）
3. **移除主页面分镜表格**：合并/拆分/复制等右键操作迁移到生图页面左侧分镜列表的右键菜单

## 目标架构

```
主页面 /comic/long-project/:projectId              生图页 /comic/panel-gen/:projectId/:chapterId
┌─ 侧栏：章节树 + 资产库树（不变）                  ┌─ 顶栏：返回/章节切换/批量推导/批量生图/导出/绘图配置
├─ tab: 原文 | 剧本（取消顶部章节标题）              ├─ 页面级 tab: 分镜 | 资产
│  原文tab: 左原文编辑(工具栏) 右AI分析(MD可编辑)    │  分镜tab: 左列表(右键菜单,无hover按钮)
│  剧本tab: 左原文只读 右剧本(MD可编辑)+跳转入口     │           中预览+资产tab(不变)
│  底部: PromptRunBar(模型/模板/发送前确认/执行)     │           右[分镜内容|提示词]切换tab
└─                                                 └─ 资产tab: 提取入口+审核+资产生图工作台
```

数据流：`chapterAnalyses/chapterScripts`（每章一份 upsert）→ 分镜 run（剧本主输入）→ `panelArtworks`（不变）→ 资产提取 run（panelAppearances 确定性统计）→ 确认后 auto-text 回填分镜绑定。

| 风险                            | 应对                                                |
| ----------------------------- | ------------------------------------------------- |
| panelArtworks 在合并/拆分/重跑后的归属迁移 | ops/run 迁移时逐行保留现有逻辑；回归：合并后缩略图、8秒撤销、重跑后已推导描述保留/标过期 |

| 候选改名后 panelAppearances 过期     | update candidate 时重算                              |

## 验证方式

每阶段结束跑 `npx vue-tsc --noEmit`；阶段二三保持旧签名兼容可随时中断发布。最终端到端手测：

1. 左侧录入原文（也可以编辑） → 分析原文（发送前确认改 prompt）→ 右列编辑分析 → 原文改动后出现"原文已变更"徽标
2. 切剧本 tab → 生成剧本 → 编辑 → 进入分镜生图
3. 生图页：生成分镜（有/无剧本两种）→ 右键合并（成图归属）/拆分/复制/撤销 → 分镜内容 tab 逐镜编辑标 stale → 提示词 tab 推导 → 批量生图 → 导出
4. 资产 tab：提取（审核页可见 panelAppearances 次数）→ 改候选 → 确认 → 分镜绑定自动回填（auto-text）→ 资产生图工作台可用
5. 旧项目兼容：无分析/剧本的旧章节直接进生图页，旧 storyboardRuns 正常推导/生图
